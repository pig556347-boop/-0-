# KICK Back temporary original audio

All nine WAV recordings are generated from original oscillators and seeded noise by `Tools/generate_audio.py`. No samples, commercial recordings, external melodies or third-party music are used. These project-created assets can be used and modified with this game; no third-party attribution is required.

Mono 22,050 Hz / 16-bit PCM. Lobby: 90 BPM, eight bars. Battle: 120 BPM, eight bars. Both are instrumental loop sketches, not final commissioned music. Hit, Whoosh, Block, Parry, Down, Menu and Success are separate effects. Music and effects use independent settings; Master controls both. Browser playback begins after user interaction.
