# 결정 기록

사용자 요청이 첨부 문서의 전체 게임 MVP보다 우선합니다. 문서 내 다른 게임 재사용 문구는 허가로 취급하지 않았습니다. 기존 게임 파일을 열어 구현 참고자료로 삼거나 가져오지 않았습니다.

| 항목 | 선택 | 이유 |
|---|---|---|
| 프로젝트 분리 | `SchoolEscape/`, `feat/school-escape-exploration-beta` | 기존 게임·배포 보존. 별도 worktree는 만들지 않음 |
| 문서에 번호가 있는 선택 | **후보 1** | 사용자의 1번 선택 규칙. 2층 이미지 2만 참고, 이미지 3의 후보 2는 사용하지 않음 |
| 에디터 버전 | Unity 6000.0.62f1 LTS | 별도 지정이 없어 지원되는 Unity 6 LTS를 새 프로젝트 기준으로 선택. 다른 프로젝트의 설정 파일을 복사하지 않음 |
| 시점 | XZ 이동, 57도 하향 정사영 2.5D | 탑다운 길찾기와 캐릭터 실루엣 가독성을 함께 확보 |
| 이동 | 걷기 2.6m/s, 달리기 4.7m/s, 대각선 정규화 | 복도 탐방과 긴 거리 왕복의 기본값. 공격·점프·회피 입력 없음 |
| 배치 단위 | 셀 1.25m, 캐릭터 키 1.68m, 반경 0.27m, 문 폭 1.02m | 교체 가능한 모듈 비율을 일정하게 유지 |
| 복도 | 대부분 폭 3–4셀, 중앙홀은 더 넓게 | 실제 이동·카메라 여유를 확보한 평면도 해석. 원본 이미지의 정확한 CAD 복제는 아님 |
| 계단 방식 | 발판에 걸어 들어가면 자동 이동, 고정 도착지 | 후속 사용자 요청으로 E 상호작용을 제거. 평면 발판/난간은 임시 모듈이며 연속 고도 계단은 아님 |
| 계단 안전 | 0.75초 간격, 트리거 밖 도착, 도착 계단 주변 3.2m를 벗어난 뒤 재진입, 열린 셀 검사 | 벽 속 스폰·입력 유지/대기 중 연속 전환·낙하 예방 |
| 방 | 기본 닫힘 + E로 독립 방 입장/퇴실 | 최신 요청에 따라 복도와 내부를 별도 공간으로 분리. 음악실 묶음만 내부 연결 |
| 1층 | 문서 이미지 1 기반. 도서실/교직원 화장실 사이 단일 주 계단 | 현관/홀/양쪽 우회와 복도 끝을 보존 |
| 2층 | 문서 이미지 2의 후보 1만 사용 | 불투명한 중앙 벽 섬. 아래층 시야나 후보 2 오픈홀 없음 |
| 3층 | 문서 이미지 4 기반 중앙 분기와 벽 섬 추가 | 외곽 순환만으로 끝나지 않도록 굴절/내부 우회/막다른 길 포함 |

| 지도 | 현재 층 안내도, Tab 확대 | 별도 선택지가 정해지지 않은 사항의 기본안. 탐방 경로를 검토하기 쉬움 |
| 음향 | 이번 임시 버전은 무음 | 확보된 독립 음향이 없으며 불필요한 이벤트 연출을 추가하지 않음 |
| 빌드 경로 | 이 프로젝트의 `Builds/WebGL` | 기존 배포나 저장소의 배포 워크플로를 수정/실행하지 않음 |
| 브라우저 보조물 | 독립 검토판을 명시 | Unity 실행 제한 중에도 실제 조작으로 동선을 검토. Unity/WebGL 완료로 간주하지 않음 |

## 맵 백업 반영

`1268055a35266ca70e1c1302c2d5852ba537a2ad`의 맵 백업을 실제로 읽고 외곽 크기·간격에 반영했습니다. [대조표](BACKUP_RECONCILIATION.md)에 출처와 반영/보류 항목을 구분했습니다. 기존 문 가독성 제안 중 1번인 벽 단면 처리를 기본으로 선택하고 문틀·문턱을 더했습니다. 단면은 표시만 바꾸고 벽·문 충돌과 내부 진입 금지는 유지합니다. 도서실 내부 초안과 방송실 폐기안은 확정 내부로 구현하지 않습니다.

## 후속 요청: 방 내부 제작

사용자의 “방구조도 내가 줬잖아 내부는 왜 안만들어”를 내부 제작 요청으로 받아들여 초기 내부 제작 금지를 변경했습니다. 새 이미지 DOCX는 전송 제한으로 미열람 상태이므로 실제 읽은 GitHub 백업 텍스트를 기준으로 합니다.

| 선택 | 기본안과 이유 |
|---|---|
| 제작 대상 | 교실 V1 18개, 음악실 V3, 미술실/별도 창고, 도서실 초안 2개. 백업에서 구체 구조가 있는 방을 구현 |
| 입퇴실 | 열린 미닫이 출입구를 직접 통과. 계단과 동일하게 E키를 요구하지 않음 |
| 교실 배치 | 앞쪽 칠판·천장 TV·교탁, 책걸상, 뒤쪽 정확히 4열×8행 사물함. 작은 빈교실은 책상 수를 줄여 동선을 확보 |
| 음악실 | 메인실+작은 연결 통로+오래된 보컬룸+악기창고. 얇은 칸막이와 실제 출입 틈으로 연결하고 현대 스튜디오 스타일 배제 |
| 미술실 | 작업대·이젤·석고 흉상·세면대. 기존 반 교실 면적 창고와 짧은 내부 통로 연결 |
| 도서실 | 1번 기본안으로 서가·열람석·대출대가 있는 고정 초안 사용. 최종안으로 간주하지 않음 |
| 가시성 | 내부 벽은 낮게 표시하고 물리 충돌 높이는 유지. 가구를 통과하지 않고 주요 구역에 왕복 가능하게 배치 |
| 에셋 | 독립 제작한 기하 모듈로 대체, 최종 모델/텍스처 교체 목록 유지 |
| 기능 범위 | 걷기·달리기·입퇴실·계단만. 자료의 조사/드랍/숨기/괴이는 이번 요청의 자동 허가로 해석하지 않음 |

경로 검사에서 얇은 벽 양쪽 셀 중심은 안전하더라도 두 점 사이가 막힐 수 있어, 구간을 분할 검사한 경로로 실제 컨트롤러를 움직입니다. 벽 충돌을 제거하여 검사를 통과시키지 않습니다.

## 최신 수정: 독립 방 공간 / 기본 닫힘 / E 입장

사용자는 문을 열고 들어갈 때 층 이동처럼 독립된 방으로 이동하고, 들어가기 전 내부가 보이지 않으며 방 안에서는 해당 맵만 보이도록 요청했습니다. 기존의 복도와 이어진 열린 방 배치는 이 요청으로 변경합니다.

| 선택 | 이유 |
|---|---|
| 방마다 별도 고정 그리드 | 복도 외곽 크기와 내부 크기를 분리하고 현재 공간만 표시 |
| 닫힌 문 + E + 0.22초 열림 후 이동 | 사용자가 지정한 입장 방식. 나가기에도 E 사용 |
| 진입/퇴실 중 이동 정지 + 완료 후 0.6초 간격 | E 연타/홀드·키 반복으로 여러 공간을 연속 이동하는 문제 방지 |
| 복귀 지점 | 해당 방 문 앞의 원래 층 안전 셀. 진입 전 위치가 벽에 너무 가까워도 안전하게 복귀 |
| 음악실 묶음 | 메인/통로/보컬룸/악기창고는 하나의 맵으로 연결. 내부 포털 없음 |
| 미술실 창고 | 최신 “음악실만 예외”를 적용해 독립 맵으로 변경 |
| 실내 크기 | 교실18×18, 음악실28×28, 미술실26×24, 창고18×14, 도서실34×32셀. 인물/가구 크기는 유지 |
| 책장 | 겹친 몸체를 얇은 판 구조로 바꾸고 책간/책장 간격 확보. 책의 그림자 생성/수신을 꺼 작은 표면의 반짝임 감소 |

이전 절의 열린 출입구·미술실 창고 직접 연결은 과거 단계의 기록입니다. 최신 구현은 이 절이 기준입니다.

| 항목 | 적용 내용·이유 |

| 서관/별관 연결 | 현재 채팅 손그림 기준. 본관2층 후보1 유지, 양쪽으로37.5m/38.75m 걸어가는 통로. 종단 봉쇄로 건물 내부 제작 범위를 확장하지 않음 |

검사는 새로운4×2모듈/비정형 음악실/긴 통로를 기준으로 수정했으며, 실제 이동으로 이전 E입퇴실·계단 왕복·책 안정성도 함께 확인합니다.
