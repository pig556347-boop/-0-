01. 프로젝트 정의
폐교탈출의 정체성을 먼저 고정한다.
 LOCKED  장르: 탑다운/2.5D 폐교 탈출 액션 호러
현재 KICK Back에서 쌓아둔 탑다운/2.5D 이동·전투·피격·사운드·WebGL 검증 경험을 최대한 살린다. 1인칭 3D 전환은 이 프로젝트 범위에서 제외한다.
게임 한 문장
핵심 피치  매판 달라지는 폐교에서 3개의 열쇠와 사라진 친구들을 찾아, 추적자와 괴이를 피하거나 싸워 돌파한 뒤 정문을 열고 흑막을 쓰러뜨려 교문 밖으로 탈출한다.

모든 공포를 도망만으로 해결하지 않는다. 처치 가능한 몹은 KICK Back식 근접 액션으로 대응한다.

추가 시안 01. 교실 출석부·자리배치도 퍼즐 시스템
핵심 방향  일반 교실을 단순 아이템 보관방이 아니라, 출석부와 자리배치도를 해석해 특정 학생의 실제 책상을 찾아가는 방탈출형 탐색 공간으로 사용한다. 같은 교실이라도 새 게임마다 학생 이름과 역할이 바뀌어 반복 플레이의 체감을 달리한다.
1. 모든 반 공통 고정 오브젝트
오브젝트
기능
교탁
출석부와 자리배치도가 항상 놓여 있는 기준 조사 포인트. 교탁 자체도 별도 조사 가능.
출석부
학생 번호, 이름, 역할 정보를 확인하는 문서. 반장/부반장 등 퍼즐에 필요한 역할을 식별하는 핵심 자료.
자리배치도
학생 이름은 표시하지 않고 숫자만 표시. 출석부에서 확인한 학생 번호를 실제 책상 위치로 변환한다.
칠판
낙서, 수업 흔적, 맥거핀, 실제 힌트가 섞여 등장. 모든 글이 퍼즐 정답은 아니다.
학생 책상
각 책상은 개별 조사 가능. 서랍 및 책상 주변에 퍼즐용 아이템/열쇠가 배치될 수 있다.
사물함
교실 V1 규격인 4열 x 8행을 유지. 개별 상호작용 및 조사 가능.
2. 자리배치도 규칙
자리배치도에는 학생 이름을 적지 않는다. 각 자리에는 학생 번호만 표시하며, 플레이어는 출석부의 이름/역할 정보를 먼저 읽은 뒤 해당 번호가 어느 자리에 있는지 다시 자리배치도에서 찾아야 한다.

3. 출석부 정보 구조
출석부는 자리 위치를 직접 알려주지 않고, 학생 번호와 이름 및 필요한 역할만 제공한다. 반장 찾기 퍼즐에서는 출석부를 통해 반장의 이름과 번호를 확인한 뒤 자리배치도로 이동해야 한다.

4. 대표 퍼즐 흐름
1. 힌트 발견: “반장 자리에 2학년 교무실 열쇠를 둔 것 같다.”
2. 교탁 조사 -> 출석부 확인.
3. 출석부에서 이번 판 반장이 “성지민 / 07번”임을 확인.
4. 교탁의 자리배치도에서 07번 자리 위치 확인.
5. 교실 안 실제 07번 책상으로 이동.
6. 07번 책상 서랍 조사 -> 2학년 교무실 열쇠 획득.
5. 칠판 콘텐츠 규칙
• 무관 낙서: 학생 이름, 장난, 시험 일정, 수업 메모처럼 퍼즐과 관계없는 글.
• 맥거핀: 의미심장하지만 현재 루트의 정답과는 관계없는 문구.
• 실제 힌트: 특정 학생, 역할, 방, 물건 위치를 간접적으로 지시하는 문구.
• 같은 칠판이라도 매판 콘텐츠 종류와 문구를 바꿀 수 있도록 데이터화한다.
6. 학생 이름 1,000개 랜덤 풀
학생 이름은 새 게임(런) 시작 시 각 반에 새로 배정한다. 전 판의 반장이 이윤석이었다면 다음 판에는 성지민, 그 다음 판에는 다른 학생이 반장이 되는 식으로 같은 퍼즐 틀을 유지하면서도 표면 정보를 바꾼다.
항목
규칙
이름 풀
총 1,000개 고유 전체 이름. 별도 파일 「폐교탈출_학생이름풀_1000개.xlsx」에 저장.
런 생성
새 게임 시작 시 현재 사용되는 모든 반의 학생 이름을 이름 풀에서 중복 없이 배정.
역할 배정
반장/부반장 등 역할도 런 생성 시 학생 중 무작위 지정.
일관성
한 번 생성된 런에서는 출석부, 메모, 책상, 사물함, 타 방의 쪽지에서 동일 학생 이름/번호를 유지.
세이브/로드
저장 후 불러와도 같은 런에서는 학생 이름이 다시 바뀌지 않는다. Run Seed 또는 저장 데이터에 배정 결과를 보존.
제외 규칙
정치인, 강력범죄자, 사용자가 제외를 요청한 문제 공인과 동일하거나 매우 유사한 이름은 이름 풀 생성 단계에서 최대한 배제.
출시 전 검수
실존 인물 전체와의 우연한 동명이인을 완전히 제거하는 것은 현실적으로 불가능하므로 출시 빌드 전 최종 이름 검수 권장.

추가 기획 — 초반 첫 교실 열쇠 루트 규칙
핵심 원칙
학생 교실의 잠금은 무조건 '해당 교실 전용 열쇠'로만 해제한다. 학생 교실 자체에는 비밀번호·방향키 자물쇠·공구 해제 방식을 적용하지 않는다.
게임 시작 직후 플레이어가 처음으로 얻게 되는 학생 교실 열쇠까지의 선행 루트는 최대 3단계 이하로 제한한다.
초반 첫 열쇠 루트는 플레이어가 주변 조사 → 단서 확인 → 잠금 해제 → 새 공간 진입이라는 기본 규칙을 익히는 첫 퍼즐 체인으로 사용한다.
첫 학생 교실을 연 이후부터는 본격적인 랜덤 탐색·연쇄 해금 구조로 확장한다.
초반 첫 열쇠 루트의 정의
현재 갈 수 있는 공간이 제한된 상황에서, 플레이어가 탐색 가능한 장소에서 단서를 발견하고 최대 3개의 선행 장소/행동을 거쳐 첫 학생 교실의 전용 열쇠를 얻도록 한다.
예시 루트
1) 교직원 여자화장실 조사 → 쪽지 발견: '+6342'
2) 양호실(보건실) 숫자 잠금장치에 6342 입력 → 입장 → 교무실 열쇠 획득
3) 교무실 입장 → 2학년 1반 열쇠 획득
4) 2학년 1반 입장 → 여기서부터 본격적인 탐색 루프 시작
랜덤 생성 규칙
첫 학생 교실 후보는 런마다 바뀔 수 있다. 예: 2-1, 2-2, 2-3, 2-4 중 하나.
첫 교실 열쇠 획득까지 필요한 선행 장소/행동 수는 1~3개로 제한한다.
초반 선행 루트에는 현재 시점에서 아직 들어갈 수 없는 방을 요구하지 않는다.
자기 자신을 여는 열쇠가 그 잠긴 방 안에 생성되는 순환 구조를 금지한다.
초반 루트에는 최소 한 번의 단서 읽기/해석을 포함할 수 있으나 지나치게 난해한 추론은 피한다.
선행 장소의 잠금은 열쇠, 숫자 비밀번호, 방향키 자물쇠, 간단한 아이템 확인/사용 등을 조합할 수 있다.
단, 최종적으로 학생 교실 문을 여는 수단은 반드시 해당 교실 전용 열쇠여야 한다.
난이도 의도
게임 시작부터 모든 공간을 열어두지 않고 짧은 1~3단계 연쇄 퍼즐을 통해 첫 교실을 열게 함으로써, 플레이어가 기본 탐색 규칙을 자연스럽게 익히도록 한다. 첫 단추 이후에는 열쇠와 단서의 위치가 런마다 달라져 매판 다른 탐색 경험을 제공한다.

추가 기획 — 구역 단계 해금 및 런별 잠금 랜덤화
핵심 목적 — 게임 시작 시 1~3층과 모든 별동을 한꺼번에 열어두지 않고, 플레이어의 탐색 범위를 단계적으로 확장한다. 현재 열린 구역을 충분히 조사하는 과정에서 다음 구역 카드키와 다른 아이템/열쇠/단서를 자연스럽게 발견하게 한다.
1. 구역 단위 카드키 진행
게임 시작 시 기본 탐색 범위는 본관 1층 등 지정된 시작 구역으로 제한한다.
2층으로 올라가려면 2층 카드키가 필요하다.
2층 카드키는 반드시 시작 시점부터 열려 있는 공간 중 하나에 생성한다. 카드키 획득 자체가 잠긴 공간을 선행 조건으로 요구해서는 안 된다.
2층을 개방한 뒤에는 3층 카드키를 1~2층의 현재 접근 가능한 공간 중 하나에서 찾게 한다.
옥상, 별관, 서관 역시 각각 전용 카드키 또는 구역 출입권한을 요구한다.
각 구역 카드키는 해당 구역 바깥의 이미 접근 가능한 영역에 배치해 소프트락을 방지한다.
새 구역이 열릴 때마다 탐색 범위와 획득 가능한 아이템 풀이 확장되는 구조로 설계한다.
2. 기본 진행 예시
• 시작: 본관 1층 일부 또는 전체의 기본 공개 공간 탐색
• 1층 탐색 중 2층 카드키 발견 → 2층 계단/출입 게이트 해제
• 1~2층 탐색 중 3층 카드키 발견 → 3층 개방
• 개방된 본관 구역을 탐색하며 별관 카드키 / 서관 카드키를 각각 발견 → 별동 확장
• 후반 접근 가능한 구역에서 옥상 카드키 발견 → 옥상 개방
3. 카드키 생성 보장 규칙
다음 구역 카드키는 반드시 현재 런에서 접근 가능한 공간에 존재해야 한다.
다음 구역 카드키를 얻기 위해 그 다음 구역에 먼저 들어가야 하는 역전 의존성을 금지한다.
카드키는 항상 바닥에 노출시키지 않아도 된다. 책상 서랍, 사물함, 보관함, 특정 퍼즐 보상 등 현재 접근 가능한 공간 안에서 숨길 수 있다.
카드키를 찾는 도중 학생 교실 열쇠, 공구, 비밀번호 힌트, 회복/소모 아이템, 메모 등을 발견하도록 배치해 탐색 자체에 보상을 준다.
카드키 위치 후보는 런마다 변경한다. 단, 후보군은 현재 접근 가능한 공간으로 필터링한 뒤 무작위 선택한다.
4. 비밀번호·방향키 자물쇠 런별 랜덤화
숫자 비밀번호는 매 런 새로 생성한다. 지난 판에 사용한 번호를 외워서 바로 열 수 없게 한다.
방향키 자물쇠의 입력 순서도 매 런 새로 생성한다.
런 시작 시 잠금장치의 정답 데이터를 먼저 생성하고, 해당 정답을 알려주는 쪽지·칠판·메모·문서·환경 단서도 같은 데이터에서 함께 생성한다.
예: 양호실 비밀번호가 이번 런 6342라면 교직원 화장실 쪽지에도 6342를 유도하는 단서가 생성된다. 다음 런에 8175가 생성되면 쪽지 내용도 8175에 맞춰 변경된다.
힌트와 정답을 서로 독립 랜덤으로 뽑지 않는다. 반드시 동일한 PuzzleId/RunSeed를 공유해 모순이 생기지 않도록 한다.
세이브 후 재접속 시에는 같은 런의 비밀번호와 방향키 정답을 유지한다. 새 게임 시작 때만 재생성한다.
5. 학생 교실 규칙과의 관계
학생 교실 문은 계속 해당 교실 전용 열쇠만으로 해제한다. 카드키는 층/별동 같은 큰 구역을 여는 장치이고, 교실 열쇠는 개별 교실을 여는 장치로 역할을 분리한다.
• 구역 카드키 = 탐색 범위 확장
• 학생 교실 열쇠 = 개별 방 개방
• 비밀번호/방향키/공구/조건 아이템 = 카드키나 다른 열쇠·단서에 도달하기 위한 중간 퍼즐
6. 플레이 의도
초반부터 학교 전체를 검색하게 하지 않고 작은 탐색 범위에서 시작해 새 구역을 하나씩 개방한다. 플레이어는 2층 카드키를 찾으려 주변을 자세히 조사하다가 학생 교실 열쇠나 공구, 메모, 다른 퍼즐 단서를 우연히 발견하게 되고, 그 결과 단순히 카드키만 찾는 것이 아니라 학교 안의 여러 상호작용에 자연스럽게 관심을 갖게 된다. 구역이 열릴 때마다 새로운 장소가 생기므로 진행감과 성취감도 분명해진다.

추가 기획 — 특별실 잠금 기믹 런별 랜덤화
핵심 규칙
학생 교실은 기존 규칙을 유지하여 항상 해당 교실 전용 열쇠로만 연다.
음악실·미술실·양호실·방송실·창고·자료실 등 특별실/공용실은 새 게임마다 잠금 방식 자체가 달라질 수 있다.
현재 기본 잠금 해제 수단은 전용 열쇠, 절단기(쇠사슬 절단), 4자리 비밀번호, 6자리 비밀번호, 비밀번호가 적힌 쪽지/기록물로 구성한다.
같은 방이라도 어떤 런에서는 열쇠식, 다른 런에서는 쇠사슬+절단기, 또 다른 런에서는 4자리 또는 6자리 비밀번호식이 될 수 있다.
런 생성 시 먼저 각 방의 잠금 타입과 정답/필요 아이템을 정하고, 그 다음 반드시 현재 접근 가능한 공간에 대응 단서나 도구가 배치되도록 한다.
예시 — 음악실
런 A: 음악실 문 잠금 = 음악실 전용 열쇠 → 현재 접근 가능한 방들 중 한 곳에서 열쇠 획득.
런 B: 음악실 문 잠금 = 쇠사슬 → 절단기를 찾아 쇠사슬 절단 후 입장.
런 C: 음악실 문 잠금 = 4자리 비밀번호 → 런에서 생성된 힌트/쪽지를 찾아 입력.
런 D: 음악실 문 잠금 = 6자리 비밀번호 → 다른 기록물 또는 여러 단서를 조합해 정답 확보.
런 생성 규칙
잠금 타입은 방마다 후보군을 가진다. 모든 방이 모든 타입을 반드시 지원할 필요는 없다.
특별실마다 어울리는 타입에 가중치를 줄 수 있다. 예: 창고/체육 관련 공간은 쇠사슬 확률을 높이고, 행정/통제 관련 공간은 비밀번호 확률을 높일 수 있다.
같은 런에서 지나치게 같은 방식만 반복되지 않도록 전체 분포를 조절한다. 예: 열쇠식만 연속 5개 이상 배정되지 않게 제한.
4자리/6자리 비밀번호는 새 게임마다 재생성한다. 해당 숫자를 가리키는 쪽지·기록·칠판·컴퓨터 로그도 같은 PuzzleId/RunSeed에서 함께 생성한다.
절단기가 필요한 방이 생성되면 절단기는 반드시 그 방을 열기 전에 접근 가능한 구역에 존재해야 한다.
전용 열쇠가 필요한 방도 동일하게 자기 방 안에 자기 열쇠가 생성되는 소프트락을 금지한다.
한 방에 열쇠+절단기+비밀번호를 모두 요구하는 식으로 중첩하지 않는다. 일반 특별실은 기본적으로 1개의 주 잠금 기믹만 배정한다.

추가 기획 — 절단기 사용 비중 제한 규칙
핵심 원칙
절단기는 한 런에서 '방/교실 자체의 출입문을 여는 용도'로는 최대 1곳에만 배정한다.
예: 이번 판 음악실이 쇠사슬+절단기 방식이라면, 다른 특별실/공용실의 출입문에는 절단기 해제 방식을 배정하지 않는다.
학생 교실은 기존 규칙대로 항상 해당 교실 전용 열쇠로만 해제하므로 절단기 대상에서 제외한다.
절단기가 한 판의 진행 전체를 지나치게 지배하지 않도록, 출입문 해제 용도는 1회성 핵심 기믹으로 제한한다.
허용되는 추가 절단기 사용
사물함에 감긴 체인 절단
캐비닛/철제 보관함의 체인 절단
철망문 또는 소형 철제 펜스 일부 절단
체인으로 묶인 상자/도구함 개방
길을 막은 얇은 와이어/체인 장애물 제거
위와 같은 소형 오브젝트 해제는 여러 곳에서 등장해도 된다. 단, 절단기를 얻은 뒤 모든 방 문을 연속으로 푸는 만능키처럼 느껴지지 않도록 보상·아이템 탐색용 보조 기믹으로 사용한다.
런별 배정 예시
런 A: 음악실 문 = 쇠사슬+절단기 / 미술실 = 4자리 비밀번호 / 보건실 = 열쇠 / 방송실 = 6자리 비밀번호
런 B: 미술실 문 = 쇠사슬+절단기 / 음악실 = 열쇠 / 보건실 = 6자리 비밀번호 / 방송실 = 4자리 비밀번호
런 C: 방송실 문 = 쇠사슬+절단기 / 음악실 = 4자리 비밀번호 / 미술실 = 열쇠 / 보건실 = 6자리 비밀번호
랜덤 생성 제약
DoorUnlockType=CUTTER가 출입문 기준으로 이미 1개 배정되면 이후 출입문 후보에서는 CUTTER를 제외한다.
절단기 아이템은 절단기 대상 방에 도달하기 전에 접근 가능한 구역 안에 반드시 생성한다.
절단기 대상 출입문이 없는 런도 허용할 수 있다. 즉 절단기를 매판 강제로 등장시키지 않아도 된다.
절단기를 획득하지 않아도 진행 가능한 런이라면, 절단기는 선택적 보조 오브젝트 해제용으로만 등장할 수 있다.
