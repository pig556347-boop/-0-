# 이전 추격 베타 0.7 — 당직자·스태미나·소리

이 문서는0.7 구현 당시의 기록입니다. **현재0.8의 랜덤 지정 스폰·독립 배회·시청각 감지·포기 조건·개발ON/OFF·아이템 탈출은 [ITEMS.md](ITEMS.md)**가 기준이며, 감지 설계 근거는 [PURSUIT_RESEARCH.md](PURSUIT_RESEARCH.md)에 있습니다. 아래 고정 순찰·12m시야·10초추격/2초수색·탈출없음 설명은 과거 규칙입니다.

2026-10-23 최신 사용자 요청으로 탐방 베타에 추격자와 스태미나, 기본 환경음·문·계단·추격 음향을 추가했다. 최초 탐방 범위의 추적자 제외 조건은 이 후속 요청 범위에서 변경한다. 전투·공격·무기·점프·회피·괴이 이벤트·열쇠·퍼즐·구출·랜덤 생성은 구현하지 않는다.

## 외형과 이동

- 선택 1: 외형 시안 02의 **당직자** 한 명을 사용한다. 플레이어 약 1.68m 대비 제작 목표 키 2.4m, 어깨 약 0.87m. 굽은 등·기울어진 창백한 얼굴·긴 팔과 손가락·녹색 당직복·세로 명찰을 독자적인 게임용 기하 모델로 제작했다. 이미지의 실사 렌더 품질을 달성한 최종 모델이라는 뜻은 아니다.
- 순찰은 고정 경로이며, 벽·닫힌 문·학교 가구·봉쇄부를 통과하지 않는 격자 경로를 사용한다. 웹 순찰 1.35m/s, 추격 3.3m/s이며 플레이어 걷기 2.6m/s·달리기 4.7m/s와 구분한다.
- 시야 12m 내에서 장애물로 가려지지 않은 플레이어를 감지한다. 달리기는 8m 안에서 소리로도 감지한다. 웹은 시야를 놓쳐도 마지막 위치를 향해 최대 약 10초 추격하고 2초 수색한 뒤 순찰한다. 직교 카메라에서 다른 방의 내부를 미리 보여주지 않는다.
- 플레이어가 사용한 문·계단의 경로를 추적한다. 추격자가 실제 출입 지점까지 이동한 뒤 웹 기준 문 1.25초·계단 1.45초를 거쳐 같은 공간으로 들어온다. 방에 들어간 순간 추격이 초기화되지 않는다. 문 경로는 약 18초 동안 유효하며 공간 사이를 무조건 순간이동해 플레이어에게 붙이지 않는다.
- 도착점 주변의 안전한 위치를 검사하고 플레이어와 겹치면 잠시 기다리거나 인접한 안전 지점을 선택한다. 시작 4초·새 공간 도착 직후 약 0.8초의 웹 잡힘 유예가 있다. 약 0.7m 안에서 장애물 없이 닿으면 잡힘 화면을 표시하고 이동을 멈춘다. 현관 재시작 버튼으로 위치·스태미나·문·추격 상태를 초기화한다.

## 스태미나

- 선택 1: 최대 100, 이동 중 달리기 초당 20 소모로 약 5초 유지.
- 마지막 달리기 이후 1.5초부터 초당 18 회복하며 걷기·정지 중에도 회복한다.
- 0까지 소모하면 지침 상태. 25까지 회복하기 전에는 Shift를 눌러도 걷는다.
- 벽에 막히거나 제자리에서 Shift만 누를 때는 소모하지 않는다. 대각선 속도는 정규화한다. HUD는 실제 달리기 상태와 남은 양을 표시한다.

## 소리와 일시 정지

- 외부 게임의 음원이나 음악을 가져오지 않았다. 브라우저는 WebAudio 합성, Unity는 런타임 PCM 합성으로 바람·건물 저음, 걷기/달리기/계단 발소리, 목재문 열림·닫힘, 추격 리듬과 저음, 지친 호흡, 잡힘 효과음을 만든다.
- 실제 이동과 문·계단 이벤트에 연결한다. 추격 소리는 추격 상태에 따라 서서히 전환한다. 기본 음량 40%, 음소거와 음량 조절 제공. 브라우저는 시작 클릭 전 AudioContext를 만들거나 소리를 재생하지 않는다.
- Esc 또는 창 포커스 이탈 시 게임·추격·문 이동·소리를 함께 멈춘다. 계속하기를 눌러 재개한다. 재시작과 일시정지에서 효과음이 쌓이지 않도록 처리한다.
