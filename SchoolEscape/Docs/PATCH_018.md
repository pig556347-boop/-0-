# 폐교탈출 0.18 · 도서실, 배회 음악가, 옥상 탐방

2026-11-02 KST. 중단 지점의 변경사항을 보존해 이어서 구현했다. 기존 게임·main·기존 배포는 교체하지 않는다. 멀티플레이는 가능 여부에 대한 질문으로 처리했으며 구현 범위에 넣지 않았다.

## 이번 변경

- 도서실 반납 순서 퍼즐과 보관함 해금 조건을 제거했다. 서가·책상·수납함은 일반 조사로 이용한다. 입구 대출대는 사서 선생님 책상으로 꾸미고 의자, 모니터, 기록물, 작은 자료함을 추가했다. 손전등은 기존 안쪽 비상 물품 보관함에서 바로 회수하며 과학실과 같은 3층 조건을 유지한다.
- 음악실의 기존 피아노 가속·불협화음·등장 연출은 유지한다. 음악가는 음악실 내부에서 무작위 목적지로 배회한다. 10m 이내 시야(정면, 2m 근접 감지) 또는 7m 이내 달리기 소리를 감지하면 마지막 발견 위치를 추격한다. 벽/가구에 막힌 위치를 투시하지 않는다. 마지막 위치에 도달하거나 8초간 재발견하지 못하면 배회로 돌아간다. 이 음악가는 현재 음악실 내부 전용이며 본관 전체를 돌아다니는 당직자와 별개다. 배회 중에는 긴박한 추격 음악을 켜지 않는다.
- 옥상에 급수탑, 화단, 벤치, 점검 상자, 호스 릴, 난간과 배수구를 추가했다. 바닥은 흙 대신 콘크리트 계열이며 실외 분위기를 적용했다. 옥상도 자동 계단을 사용할 수 있도록 실외 공간의 계단 처리와 HUD를 수정했다.
- 매판 교문 열쇠 A/B/C 중 무작위 하나를 옥상에, 하나를 본관 실내에, 하나를 운동장에 배치한다. 구역별 위치와 바닥/수납 형태는 랜덤이다. 쏠림 방지 재배치가 이 구역 조건을 깨지 못하도록 수정했다. 옥상 카드키는 앞선 4층에서 얻는 기존 진행을 유지한다. 옥상 단서는 급수 설비와 높은 곳을 가리킨다.

## 선택과 저장

- 별도 수치 지정이 없어 탐방 속도를 높이되 일반 추격자는 달리기보다 느리고 걷기보다 빠르게 정했다. 직선 가속 덩키보이와 조리실은 별도 위협을 유지한다.
- 옥상 탐방 보상을 확실히 제공하려고 A/B/C 중 하나를 옥상에 보장했다. 세 열쇠를 미리 하나씩 교문에 꽂는 방식은 유지한다.
- 이번 도서실/배치 변경과 이전 저장 데이터가 섞이지 않도록 웹·Unity 저장 공간을 0.18로 분리했다. 0.17 저장 파일을 삭제하지 않는다. 0.18은 새 판에서 시작한다.
- 새 소품은 기존 프로젝트 재질을 사용한 임시 모듈이다. 확보된 자산은 기존 바닥·벽·폰트이며, 정식 사서 가구·옥상 설비 모델과 상세 텍스처는 추후 교체 대상이다.
