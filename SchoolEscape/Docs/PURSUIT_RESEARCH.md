# 추격 감지·포기 기준 — 공개 사례 조사

확인일: 2026-10-24(한국시간). 공개된 설명과 플레이 설계 원리를 조사했으며 다른 게임의 코드·에셋·모션·설정 파일은 읽거나 가져오지 않았다. 아래 수치는 **폐교탈출의 새 기본안**이며 다른 게임의 내부 상수나 정확한 추격 포기 시간으로 주장하지 않는다.

## 실제 읽은 자료와 적용할 원리

### 1. Alien: Isolation — 감독과 괴물의 정보는 다르다

Tommy Thompson, [The Perfect Organism: The AI of Alien: Isolation](https://www.gamedeveloper.com/design/the-perfect-organism-the-ai-of-alien-isolation), Game Developer. 본문 HTTP200 확인.

- 글은 전체 긴장도를 조절하는 감독 AI와 실제 괴물 AI를 분리해 설명한다. 감독은 플레이어 위치를 알지만 괴물은 시청각 감각과 자체 탐색으로 찾아야 한다. 짧은 원문: “the alien has to figure it out for itself”.
- 괴물은 소리나 관심 지점에 반응해 탐색하고, 한 위치까지 최단 경로로 계속 붙는 것과 다른 순회·재확인 행동을 한다.
- 긴장이 과도해지면 감독이 괴물을 다른 구역이나 환기구로 보내 쉬는 구간을 만든다는 설명이 있다. **이는 괴물의 시야 상실 타이머와 별개의 페이싱 시스템**이다.
- 폐교탈출에는 플레이어의 비공개 위치를 계속 알려주는 감독 힌트를 넣지 않는다. 랜덤 지정 스폰과 배회 목적지는 플레이어 현재 위치를 추적하는 장치로 쓰지 않는다.

### 2. Alien: Isolation — 마지막 감각 정보는 감쇠한다

같은 저자의 [Revisiting the AI of Alien: Isolation](https://www.gamedeveloper.com/design/revisiting-the-ai-of-alien-isolation), Game Developer. [저자 재게시본](https://www.aiandgames.com/p/revisiting-alien-isolation)도 본문 HTTP200 확인.

- 시야는 거리만 보는 구형 감지가 아니라 여러 시야 원뿔과 가림 여부, 감지 강도를 사용한다고 설명한다. 앞에 오래 노출되면 시각 감지가 강해진다.
- 소리는 **소리가 발생한 위치**를 조사하게 한다. 이동 방식과 소리 종류에 따라 반응이 다르며, 이후 감각 기록은 시간이 지나면 잊힌다. 짧은 원문: “each sensor detection has a rate of decay”.
- 감각이 끊겨도 마지막 관심 위치 주변을 수색하는 행동과, 평상시의 배회는 구별된다. 검색 횟수에 따른 탐색 반경 변화와 별도의 퇴장/페이싱 조절도 설명한다.
- 이 글은 정확히 동일한 초수로 모든 추격이 끝난다고 말하지 않는다. 또한 문·사물함 소리를 괴물이 듣는다고 일반화하면 안 된다. 본문은 오히려 일부 문/사물함 개폐음은 감지에 영향이 없다고 저자의 관찰 범위를 명시한다. 폐교탈출에서 문·가구 조사를 소음으로 만드는 것은 **우리 게임의 별도 선택**이다.

### 3. Frictional Games — 숨을 돌릴 틈과 탐방을 남겨야 한다

Frictional Games 공식 개발 글, [Thoughts on Alien: Isolation and Horror Simulation](https://frictionalgames.com/2014-10-thoughts-on-alien-isolation-and-horror-simulation/). 본문 HTTP200 확인.

- 글은 자사 Amnesia: The Dark Descent에서 장롱에 숨은 채 괴물이 지나가게 하는 장면을 시스템으로 만들었다고 설명한다. Outlast의 추격/회피 구간 사이에 이동·탐방 위주의 숨 돌리는 구간도 짚는다.
- 계속 숨어 기다리기만 하거나 반복해서 죽으면 공포가 답답함·반복 과제로 변할 수 있다고 지적하며, 수동적인 플레이어에게는 괴물이 더 빨리 물러나 페이스를 회복시키는 설계를 **개선안으로 제안**한다. 이는 해당 게임에 그 개선안이 이미 구현되었다는 뜻이 아니다.
- 폐교탈출은 조사·아이템 수집이 생기므로 추격 포기 이후 실제로 배회로 복귀하고, 감지 없이 플레이어의 새 위치를 계속 따라가지 않아야 한다. 아직 요청하지 않은 장롱 숨기 기능을 추가하는 근거로 이 사례를 해석하지 않는다.

## 폐교탈출 기본안 1

상태는 `배회 → 소리 조사 → 추격 → 마지막 위치 수색 → 배회`로 구분한다. 시야나 유효 소리가 새로 확인되어야 감지 위치와 시간을 갱신한다.

| 항목 | 기본안 | 이유 |
|---|---|---|
| 초기 스폰 | 검증된 지정 후보 중 매판 하나 선택. 벽/가구/계단 도착점/플레이어 바로 옆 제외 | 임의 좌표 벽 생성과 시작 즉시 포획 방지 |
| 평상시 배회 | 연결 가능한 관심 지점과 경로를 돌아다님. 플레이어 좌표를 배회 목적지로 강제하지 않음 | 접촉하기 전부터 무조건 따라오는 인상 방지 |
| 시야 | 11m, 전방120도, 벽/닫힌 문/가구의 가림 검사 | 거리만으로 벽 너머를 감지하지 않음 |
| 소리 | 달리기8m / 걷기2m / 문6m / 가구조사4m | 행동에 따라 발각 위험을 선택할 수 있게 함 |
| 소리 위치 | 발생 당시 위치만 기억. 가림과 공간 연결을 고려하며 분리된 다른 층/방의 좌표를 그대로 듣지 않음 | 소리만으로 실시간 위치를 아는 오류 방지 |
| 시야 상실 | 마지막 감지 위치까지 이동. 새 플레이어 좌표로 목적지를 갱신하지 않음 | 모퉁이를 돌아 따돌릴 수 있게 함 |
| 수색 진입 | 마지막 위치 도착 또는 새 근거 없이8초 경과 | 길이 긴 맵에서도 무한 추격을 막음 |
| 수색 | 마지막 지점 부근에서 최대4초 확인 | 문 진입 직후 즉시 안전해지지 않으면서 탐방 시간 확보 |
| 절대 포기 상한 | 새 근거 없이12초가 되면 배회 복귀 | 도달 실패/반복 경로가 추격을 영구 유지하지 않게 함 |
| 경로 불가 | 마지막 위치로 갈 수 없는 상태3초 지속 시 포기 | 닫힌 구역 앞에서 무한 집착 방지 |
| 재감지 | 새 시야/유효 소리는 기억과 추격을 다시 시작할 수 있음 | 추격 포기 자체가 무조건적인 무적 시간이 되지 않음 |
| 문/계단 | 사용 장면이나 연결된 감지 흔적을 실제로 인지한 경우에만 해당 경로를 추적 | 방 이동은 도주 수단이지만 절대적인 안전 버튼은 아님 |
| 개발용 OFF | 추적자 이동·감지·포획·추격음/근접경고를 함께 끔. 아이템과 탈출은 계속 검증 가능 | 개발 중 독립 기능 점검 |

표는 루트 작업자가 정한 구현 기준이다. 실제 구현 파일과 검사 결과가 최종 기준이며, 이후 난이도 조정 시 수치와 증거를 함께 갱신한다.

## 조사 한계

- 저자의 AI 분석 글과 개발사의 설계 글을 읽었으며 해당 게임의 비공개 내부 코드나 모든 난이도의 상수를 검증한 것은 아니다.
- GDC Vault 주소는 유지보수 페이지로 이동하여 발표 원문으로 사용하지 않았다. 최종 목록에는 실제 본문을 읽은 출처만 넣었다.
- 포기 조건을 단순히 멀어진 거리 하나로 정하지 않았다. **시야 차단 + 마지막 감지 위치 + 제한된 수색 시간 + 경로 도달 가능 여부**를 함께 사용한다.
