# 폐교탈출 0.17 · 탐방 수정과 Unity 네이티브 이식

2026-10-29 KST. SchoolEscape 전용 폴더/브랜치. 다른 게임 코드·자산은 참조하거나 수정하지 않았다. 기존 0.16 세이브와 분리하며 새 판으로 시작한다.

## 변경

- **실험복과 손전등 모두 본관 3층**. 실험복은 같은 층 보관함, 손전등은 도서실 반납 퍼즐 보상이다. 과학실 입장에는 두 물건이 필요하다.
- **쪽지는 가방 9칸에 포함**한다. 정확한 층·대상 문 이름과 비밀번호를 표시하고 해당 잠금 해제 즉시 소모한다. 실제 입장 여부는 관계없다. 교실 열쇠 단서도 휴대 가능한 쪽지다. 가이드북은 별도이다.
- 과학 준비실 코드 입력은 해당 문 잠금과 일대일로 연결한다. 과학 자료실과 준비실을 다른 문으로 명확하게 표시한다. 클릭 숫자/방향 패드, E 다시 눌러 닫기 유지.
- **개발용 마스터키**를 한 칸에 지급한다. 일반 문·카드 구역·비밀번호·쇠사슬을 해제한다. 교문 A/B/C와 과학실 장비 조건은 별도다.
- **교문 열쇠 A/B/C를 찾을 때마다 개별 삽입**한다. 삽입한 열쇠는 가방에서 빠지고 같은 판의 사망·저장 후에도 유지된다. 세 개를 꽂은 다음 E로 최종 탈출한다. 교문에 꽂힌 열쇠와 HUD 표식을 표시한다.
- 일반 공간 초기 아이템은 **수납 1개 + 바닥 1개 이하**. 쪽지·장비 포함이다. 운동장·체육관·음악실도 무제한 밀집시키지 않고 각각 수납/바닥 최대 4개로 제한한다. 사망 드롭과 플레이어가 직접 내려놓는 물건은 초기 배치 제한에서 제외한다.
- 열쇠 배치는 잠금 의존성을 따라 배분한다. 첫 교실 열쇠를 얻는 방향 단서가 그 교실에 들어가는 순환을 차단했다. 교무실 열쇠는 단서에 적힌 반장 자리에서 유지한다.
- 도서실은 대출대 기록 → 순서대로 해당 분류 서가 3곳에서 반납 클릭 → 안쪽 보관함의 손전등 순서다. 각 서가에는 그 분류 버튼만 표시하고 오답/진행률을 알려준다.
- 출석부는 번호·이름·역할 표, 읽은 기록은 선택해서 펼치는 방식으로 바꿨다. 일반적인 한국 이름 풀을 사용하며 출석부·자리·사물함 소유자를 연결한다. 학생 사물함은 8+8+8+6=30칸, 경비원 2칸(김경비·이경비), 탈의실 4칸이다.
- 가이드북은 지금 필요한 목표와 다음 열쇠/카드/해당 방 퍼즐의 단계만 안내한다. 하드·익스트림에는 위치 해답을 노출하지 않는다.
- 조리실 일상 공간은 24×20칸으로 줄였다. 끝 상자 조사 후 돌아오는 길에 붕괴와 별도 비상 통로 추격이 시작된다. 추격 중 스태미나는 무제한이다. 사망 후 안전하게 재입장하여 상자를 다시 조사하면 재추격한다. 부순 길은 같은 판에 유지된다.
- 배식장 속도는 난이도별 4.15/4.4/4.55/4.65m/s, 멀어지면 추가 가속한다. 출발 여유 1.4초. 정상적으로 계속 달리면 완주할 수 있고 오래 멈추면 빠르게 붙잡힌다.
- **미술실 움직이는 석상**: 마우스로 바라보는 방향을 바꾼다. 벽에 가려지지 않고 시야 안에 있을 때 멈추고, 돌아서면 추적한다. 해당 방에 방향 시야 마스크를 적용했다.
- **체육관 덩키보이**: 입장 후 등장, 직선에서 2.5→6m/s 가속, 꺾으면 감속한다.
- **과학실 쉐도어 2체**: 세 번째 소등 뒤 등장하고 어두울 때만 이동한다. 표본을 회수해 뒷문으로 나간다.
- **음악실 거두 음악가**: 자체 피아노 선율 가속 → 불협화음 → 등장. 기존 당직자는 시작 층의 안전거리를 둔 지정 지점 중 하나에서 출발하도록 바꿨다. 새 판은 추적자 ON, 개발 토글은 유지한다.
- 운동장과 산책로는 한 지도에 도보로 연결했다. 경비실 1인 화장실, 체육관 관람층 코치 준비실·장비 기록실을 추가했다. 서관은 직원 카페테리아·비품창고·시설관리 작업실로 정리했다.
- 쇠사슬 잠금 시각물, 실제 플레이 시간/일시정지, 키패드·열쇠·캐비넷 소리와 문·발걸음·괴물 음향을 보완했다.

## Unity 이식 범위와 한계

`Assets/Scripts/NativeRun017.cs`와 기존 C# 런타임에 잠금·휴대 쪽지·카드·분산 아이템·명단·9칸/착용1칸·가이드·단계별 퍼즐·난이도/목숨·사망 드롭·개별 교문 열쇠·저장/로드·네 특별실 괴물·조리실 재도전/파괴·로비/설정/메뉴 언어·사운드를 구현했다. Unity 안에서 JavaScript나 웹뷰를 실행하지 않는다.

`RunLayouts017.json`은 검증한 16개 배치의 콘텐츠 데이터다. C#이 매판 하나를 선택하고 비밀번호/도서 순서/교실 배치를 별도로 바꾼다. 무제한 새 아이템 배치를 생성하는 웹판과는 생성 방식이 다르다. 두 판의 저장 형식은 서로 호환되지 않는다.

**Unity 런타임 C#과 Editor 빌드 도구 컴파일을 검사한다. Unity Play와 Unity WebGL 실기 검증은 완료하지 못했다.** 실제 Editor 실행 로그에 `No valid Unity Editor license found. Please activate your license.`가 기록되었다. 현재 Editor 경로에는 WebGL 지원 모듈도 없다. 독립 웹판의 성공을 Unity 실행 성공으로 간주하지 않는다. Native UI/카메라/프레임 성능/사망과 저장 복원은 활성화된 Editor에서 확인해야 한다.

Unity 실행: Unity Hub에서 `SchoolEscape` 폴더를 Unity 6000.0.62f1로 열고 `School Escape > Open exploration` 후 Play. WebGL Build Support 설치 후 `School Escape > Build separate WebGL`을 실행하면 `Builds/WebGL`에 별도로 출력한다. 다른 게임 빌드를 덮어쓰지 않는다.

## 검증과 재개

검증 결과 원본은 `Docs/Evidence/patch017-*`에 보관한다. 브라우저 검사는 실제 Chromium에서 키 입력/버튼 조작과 런타임 이동을 사용하며, 빠른 방별 조건 검사는 QA 위치 이동/시간 진행을 함께 사용한다. 플레이어의 자연스러운 장시간 완주와 동일한 검사는 아니다.

- 16개 배치: 아이템 상한·장비 3층·마스터키 없는 잠금 의존성·반장 단서·쪽지 소비·개별 교문 열쇠 **2,425개 통과**.
- 3개 교실 배치: 접근 경로/도착 지점/교사 좌석/학년 층 **3,729개 통과**.
- 지도 구조/가구 여유/문과 계단 연결 **77,455개 통과**.
- 실제 Chromium 방별 검사와 로비/설정 검사: 최종 보고서의 빌드 SHA-256과 결과 참조.
- 전개도 Chromium **114개 보기·9개 PNG 통과**, 오류 0.
- Unity C# 컴파일과 Unity Play 실패는 서로 별도 기록한다.

재개 지점: 공개 배포 검증 완료 여부는 `Deploy/publication.json` 확인. 남은 작업은 라이선스가 활성화된 Unity에서 Play 회귀 검사, WebGL 모듈 설치 후 실제 빌드/브라우저 검사, 몬스터 최종 자산과 실제 청취/난이도 튜닝이다. 기존 Unity 검증기는 이전 탐방 범위 검사가 포함되어 있으므로 새 괴물/저장 시나리오를 추가 검증해야 한다.
