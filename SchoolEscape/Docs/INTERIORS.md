# 독립 방 맵과 E 문 입장

최신 사용자 요청에 따라 방은 복도와 **별도 맵**입니다. 기본 문은 닫혀 있고, 문 앞에서 E를 누르면 약 0.22초 문 열림 후 독립 방으로 이동합니다. 방 안에서는 해당 공간만 렌더링하고 안내도도 같은 공간만 표시합니다. 출구에서 E로 원래 층·문 앞으로 돌아오면 문이 다시 닫힙니다. 전환 중 이동과 중복 입력, 완료 후 0.6초 연속 전환을 막습니다. 계단은 복도에서 기존 자동 이동을 유지합니다.

## 공간 분리

- 본관 1/2/3층은 각자 독립 복도 공간이며, 방 내부가 복도에 노출되지 않습니다.
- 19개 교실, 음악실, 미술실, 미술실 창고, 2층 도서실, 보건실, 행정실, 컴퓨터실, 2/3층 교무실, 방송실과12개 화장실은 각각 별도 공간입니다.
- **음악실 메인실·연결 통로·보컬룸·악기창고만 같은 방 맵**을 사용합니다. 이 내부 연결부에는 E 전환이 없습니다.
- 미술실과 미술실 창고는 최신 “음악실만 예외” 요청에 따라 별도 맵으로 분리했습니다.
- 미제작 회의실/준비실 등과 외부/옥상/서관/별관 연결부는 닫혀 있습니다.

## 크기

캐릭터 키 약 1.68m, 걷기 2.6m/s, 달리기 4.7m/s, 가구 크기를 유지하고 바닥 면적과 통로를 넓혔습니다. 단순 확대 표시나 캐릭터 축소로 대체하지 않았습니다.

| 종류 | 맵 셀 | 벽을 제외한 이동 공간 |
|---|---|---|
| 교실 | 18×18 | 약 20×18.75m |
| 음악실 묶음 | 36×34 비정형 | 메인 약31.25×23.75m + 꺾인 통로/보컬룸/창고 |
| 미술실 | 26×24 | 약 30×26.25m |
| 미술실 창고 | 18×14 | 약 20×13.75m |
| 도서실 | 34×32 | 약 40×36.25m |

일반교실은 책걸상 30세트와 중앙/측면 통로, 칠판·천장 TV·교탁, 큰 한 칸으로 바꾼 4열×2행 사물함을 모듈당8칸씩4개 배치했습니다. 음악실은 피아노·음악 책걸상·초상화·보컬 연습실/악기 케이스를, 미술실은 작업대·이젤·석고 흉상/인체상/손발 모형·세면대를 배치했습니다. 도서실은 넓은 서가·열람석·대출대 초안입니다.

현재 가구는 22,422개 기하 구성 부품(2,794개 충돌 영역), 탐방 구역은 294개입니다. 독립 모델 22,422종을 확보했다는 뜻이 아닙니다. 최종 아트 교체 목록은 ASSETS.md에 있습니다.

## 책 깜빡임 수정

이전의 책장 몸체는 내부가 채워진 상자여서 책 부피와 겹쳤습니다. 현재 뒷판·측판·선반만 남긴 구조로 바꾸고, 책과 판 사이에 최소 수cm의 여유를 뒀습니다. 책 사이에도 틈을 둡니다. 작은 책 표면은 그림자 생성/수신을 끄고 책장이 그림자를 만들도록 했습니다. 브라우저 카메라 클립 범위도 조정했습니다. 겹치는 면 검사와 실제 WebGL 프레임 안정성은 최신 VALIDATION.md 결과를 확인하세요.

## 최신 수정 — 사물함·음악실 형태·소품·연결 통로

- 교실 뒤 사물함:4열×2행 모듈4개를 같은 선에 정렬. 칸 하나는0.60×0.46m로 이전0.31×0.185m 대비 앞면 약4.8배. 모듈당8칸, 교실당총32칸. 중앙 출구와 통로는 유지.
- 음악실: 큰 사각형 하나에 보컬룸/창고를 끼워넣던 구성을 폐기. 메인 합주실 옆으로 나와 한 번 꺾이는2.5m폭 통로 끝에 보컬룸을 배치하고, 통로 중간의 옆문으로 악기창고에 연결. 내부 구역은 같은 맵에서 걸어서 이동. 책걸상도 합주구역별로 나누고 무대·악보대·캐비닛·악기 케이스/첼로·장비상자·보컬 악보대를 추가.
- 교실/특별실/도서실: 수납장·교구장·게시판·시계·라디에이터·청소도구·책/공책·필기구·가방·재료카트·물감/붓·석고상·반납카트·열람가구 등의 정적 구조물 추가. 가구 크기 대신 배치와 종류를 늘림.
- 서관/별관 연결 통로:2층 후보1의 본관을 그대로 옮겨넣은101×49셀 캔버스에 양쪽 긴 연결 통로 추가. 본관 진입점에서 서관쪽37.5m, 별관쪽38.75m를 걸어가야 끝에 도달. 끝은 봉쇄하며 각 건물 내부는 미제작. 계단/문/도착지 좌표를 함께 이동.
- 기본 닫힌 문/E 독립 방 입퇴실, 방 내부 비노출, 자동 계단, 책장 안정화 유지.

음악실 방향은 확인 가능한 텍스트 백업을 바탕으로 기본1안(메인실 옆으로 나와 꺾이는 통로)을 적용했습니다. 큰 이미지 DOCX 재다운로드도32MiB제한 오류여서 해당 이미지와 방향/치수가 일치한다고 주장하지 않습니다. 현재 채팅 그림은 서관/별관 연결 통로 배치 참고로 반영했습니다.


## 신규 4종 공간 — 시안01 적용

사용자가 승인한 시안01을 기반으로 보건실(기존 양호실)·행정실·컴퓨터실과 2/3층 교무실을 추가해 총28개의 독립 실내가 되었습니다. 각 공간의 기능 구역, 크기, 연결 층은 [SUPPORT_ROOMS.md](SUPPORT_ROOMS.md)에 기록했습니다. 보건실은4병상, 행정실은L접수대와6업무석, 교무실은각16교사석과회의공간, 컴퓨터실은24PC와중앙통로를 배치했습니다. 가구 외에 창틀·벽등·시계와 소품으로 공간을 구분합니다.

기존23개 방 데이터는 변경하지 않았으며 새5개만 추가했습니다. 실제 가구와 인물의 비율을 유지한 임시 기하 모델입니다. 입퇴실은 기존E키 전환을 사용합니다.
