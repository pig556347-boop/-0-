# 0.13 — 관람층·서관·조리실 추격 (2026-10-26)

공개 웹 Chromium38개 검사 통과, 실행/콘솔 오류0. 공개 파일SHA-256이 로컬 최종 검증물과 일치한다. 별도 소스 백업과 배포는 `school-escape-source`, `school-escape-web`에 저장한다.

이번 사용자의 그림과 후속 요청을 우선 반영했다. 독립 SchoolEscape 프로젝트만 수정했고 다른 게임의 코드·모션·자산은 사용하지 않았다.

## 지도

- 체육관: 28×15m 코트, 센터라인/센터서클, 자유투 구역,3점 아크,농구대·링·점수판·공 보관함·관람석.2층 코트 위 가장자리로3층 관람통로를 연결했다. 중앙은 아래 코트가 보이는 통층이며3층 전체 바닥으로 덮지 않았다.
- 3층 조사 공간: 체육 기록실/경기 영상분석실/스포츠 동아리실. 각20×18셀 독립 공간이며 책상·선반을 조사한다.
- 체조·무용실에10×10셀 탈의실을 E문으로 연결, 사물함과 벤치 배치.
- 운동장의 서관·별관 외부문,별관 급식실 외부문,서관1층 외부문: 빗장/자물쇠/잠김표시. E로 열 수 없고 실내 연결통로를 이용한다.
- 서관: 본관2층 서쪽 긴 통로 끝에서E.1층 직원급식실/준비조리실/냉동창고,2층 경비원 기숙사실/탕비실/화장실/통제실,3층 통제구역 기록실/감시실/서버실.3개 공용 복도 포함13공간. 자동계단으로1↔2↔3층 왕복.
- 별관 급식실 옆 새 조리실에서 이번 추격 장면을 진행한다. 저장된 서관 조리시설은 직원 준비공간으로 별도 유지했다.

총 본관53·별관18·서관13개 독립 실내/공용 공간과 운동장. 열쇠 A/B/C는 기존 본관+운동장에 유지한다. 가방9칸과 가이드북/착용칸은 별개.

## 조리실 연출

1. 최초 입장: 넓은 작업 공간을 자유롭게 탐색한다.
2. 추적자ON 상태에서 들어왔던 북쪽 문으로 나가려E를 누르면 선반과 물건이 떨어진다. 북쪽 문은 막히고 그림의 노란 선을 참고한 한 칸(1.25m) 폭의 구불구불한 비상 동선만 남는다.
3.4초 준비 시간 뒤 배식장이 추격한다. 비상 유도선을 따라 서쪽 문으로 나간다. 추격자는 실제 이동하며 주변 잔해를 부숴 통로를 넓힌다. 공간이동/순간이동으로 따라붙지 않는다.
4. 실제로 부순 장애물만 현재 판의 파괴 목록에 기록한다. 퇴장 애니메이션 중 추가 파괴도 기록한다. 다시 들어오면 그 길은 열려 있고 나머지 잔해는 남는다.
5. 새 판은 원래 조리실로 복구한다. 같은 판의 재방문에는 추격 장면을 다시 강제로 시작하지 않는다. 잡혀도 난이도의 목숨/아이템 규칙을 사용하며, 남은 목숨으로 돌아오면 잔해 상태를 유지한다.

선택 기본값: 이지/노말/하드/익스트림 기본 추격속도2/2.25/2.5/2.65m/s. 경로상 거리가12m보다 벌어지면1.2m/s를 더해 긴장감을 유지한다. 플레이어 달리기4.7m/s보다 느리다. 개발 추적자OFF는 장면 시작을 건너뛰거나 진행 중 추격을 해제한다. 일시정지/인벤토리 동안 연출도 멈춘다. 조리실에는 초기 랜덤 물품을 배치하지 않아 붕괴물 밑에 필수 아이템이 갇히지 않는다.

## 새 괴물 — 배식장

당직자의 마른 긴 코트와 대비되는 낮고 넓은 덩치. 둥근 대형 솥 같은 몸통, 찌그러진 솥뚜껑 얼굴과 어두운 틈, 기름때와 그을음이 묻은 앞치마, 두꺼운 팔·작업화·큰 배식 도구를 사용했다. 회녹색·낡은 금속·누런 천으로 기존 폐교와 색을 맞췄다. 전투 없이 추격·포획만 한다. 낙하/금속 충격음과 기존3/4추격피아노를 함께 사용한다.
