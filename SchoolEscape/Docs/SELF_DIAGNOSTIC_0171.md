# 0.17.1 · 자체 플레이와 오류 수정

2026-10-30 KST. 요청: 배포본을 자체 플레이하고 오류를 진단한다. 기존 0.17 통과 결과만 재인용하지 않고 추가 시나리오를 실행했다.

## 실제로 재현한 오류 3건

| 현상 | 0.17 재현 | 수정 후 |
|---|---|---|
| 음악실 저장 후 등장 타이머 초기화 | 8초 진행 → Esc 저장 → 저장한 판 계속하기 → 0.1초로 되돌아감 | 8.1초부터 계속 진행 |
| 과학실 저장 후 소등 횟수 초기화 | 22.5초·소등 2회 → 같은 UI로 저장/로드 → 0.1초·0회 | 22.6초·2회 유지 |
| 키보드 초점으로 사망 우회 | 개발 토글 OFF→ON을 클릭해 초점을 남김 → 덩키보이에게 실제 포획 → Space → 사망 화면이 사라짐 | 포획/탈출 상태에서 토글 비활성화, 핸들러도 차단. 부활 버튼으로만 정상 재개 |

방 이벤트의 타이머·단계·소등 횟수·스폰 예약·개발 OFF일 때의 몬스터 상태를 저장하고 복원한다. 불러온 첫 프레임에서 입장 초기화가 다시 실행되지 않는다. Unity C#에도 음악실/과학실 타이머 저장을 이식했다. 0.17 저장 형식은 유지하며 이전 세이브에 없던 타이머는 복원할 수 없어 초기값을 사용한다. 새로 저장한 판부터 보존된다.

## 실제 브라우저 플레이

첫 완주: 실험복 → 도서실 기록 읽기 → 세 분류 서가 반납 → 손전등 → 과학실 표본 → 뒷문 → A/B/C 각각 회수·교문 삽입 → 최종 E 탈출. 약 **1,178m / 게임 내 5분 53초**, 13개 확인 통과, 실행·콘솔 오류 0.

완주 스크립트는 시작 위치부터 연속된 이동 컨트롤러, 문/조사 E·F 입력과 UI 클릭을 사용한다. 순간이동, 임의 아이템 지급, 강제 잠금 해제나 강제 승리 없이 진행한다. 길 찾기는 QA에서 현재 지도와 아이템 위치를 읽어 자동화했다. 개발용 추적자 OFF와 기본 지급 마스터키를 사용했으므로, 이 결과를 자연스러운 힌트 탐색이나 몬스터 ON 난이도 완주로 간주하지 않는다.

추격/저장/사망 검사는 별도로 추적자 ON에서 실행한다. 이 검사는 특정 방으로 QA 위치 이동과 시뮬레이션 시간 진행을 사용하며, 실제 덩키보이 포획·UI 부활·저장·불러오기·키보드 입력을 확인한다. 수정 전 실패 기록과 수정 후 통과 기록을 둘 다 보존했다.

## 추가 검사

- 새 랜덤 배치 **32개 / 4,838개 조건**: 교실 배치 변형을 적용한 상태에서 아이템 상한, 잠금 의존성, 반장 단서, 쪽지/교문 열쇠를 확인.
- 상태 변화 **26개**: 저장 타이머, 세 번째 소등 이후 쉐도어 등장, 개발 OFF 몬스터 저장, 추격 중 저장 제한, 초코바 회복, 비타민워터 정확한 30%·2초, 착용 분리/가방 꽉 찬 상태, 나침반 합성·소멸, 난이도별 포획/부활/중복 목숨 차감 방지, 사망 후 과학실 장비를 문 밖에서 회수할 수 있는지 확인.
- 수정본 추가 Chromium **7개 통과**: 타이머 두 종류, 실제 덩키보이 포획, 키보드 사망 우회 차단, 정상 부활, 가방 상한/아이템 보존, 실행 오류 여부.
- 지도나 신규 에셋은 이번 수정에서 변경하지 않았다.

## 접근/실행 제한

이 작업 환경에서 공개 CDN 직접 요청은 HTTP 403이었다. 배포본 SHA-256 `5466472be0e6f1844804c55a9ef57c045c13ef1ab453a4a2d91b011568c64b94`와 동일한 HTML을 로컬 HTTP로 실행해 기존 버그를 재현했다. 수정본의 외부 공개 주소 검증은 별도 GitHub Actions Chromium에서 실행하며 결과를 `Deploy/publication.json`에 기록한다.

Unity Editor도 다시 실행했으나 실제 오류 `No valid Unity Editor license found. Please activate your license.`로 Play 진입에 실패했다. C# 런타임·Editor 도구 컴파일은 성공했지만 Unity Play/WebGL은 여전히 미검증이다. 헤드리스 브라우저 검사를 일반 PC의 성능·체감 난이도·청취 검수로 대체하지 않는다.

## 기록과 재개

`Docs/Evidence/selfdiag017-*`에 수정 전·후 브라우저, 완주, 난이도/아이템 상태, 랜덤 배치, C# 컴파일/Unity 오류 기록을 보존한다. `Tools/selfdiag017_browser.cjs`, `selfdiag017_walkthrough.cjs`, `selfdiag017_lifecycle.mjs`, `selfdiag017_seeds.mjs`로 재현한다. 위치/아이템 세팅을 사용하는 테스트와 연속 이동 완주 테스트를 분리한다.

후속 검수: 몬스터 ON·마스터키 없는 자연 플레이로 힌트 난이도와 추격 균형 확인, 실제 오디오 청취, 활성화된 Unity에서 Play/WebGL. 이번 진단 결과를 모든 가능한 입력과 모든 랜덤 판에 오류가 없다는 보장으로 표현하지 않는다.

수정본 기존 Chromium 회귀 검사 43개도 통과했다. 걷기/대각선/달리기, 1~4층 왕복, 벽/문, 네 특별실 몬스터, 조리실 포획·재추격·완주, 교문 개별 열쇠 저장·불러오기·탈출을 포함한다. SHA-256 `719e5fc4b4b64b3257b28bb19ac831ba9d0da692f225b0123ee7b32482e0d62d`.

수정본 연속 이동 완주도 통과했다. 배치 시드 `102197152`, 이동 약 1,082m, 게임 내 5분 28초, 13개 확인/오류 0. 조사 지점의 소수 좌표가 가구 안쪽 격자로 반올림되는 자동 테스트 길찾기 문제는, 실제 이동으로 가까운 통행 격자에 나온 뒤 경로를 계산하도록 테스트 도구에서 수정했다. 게임 지도/충돌은 바꾸지 않았다.
