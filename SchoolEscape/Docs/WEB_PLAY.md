첫 외부 콘텐츠 확인 화면에서 **Open the page**, 게임에서 **폐교에 들어가기**를 누릅니다. 채팅의 `chatgpt.com/local/...` 파일 미리보기가 실패하거나 HTML 소스를 보여주면 위 공개 주소로 실행하세요. 해당 미리보기 화면만으로 게임 런타임 오류라고 단정하지 않습니다. 데스크톱 Chrome/Edge와 키보드 조작을 기준으로 합니다.

- WASD / 방향키: 걷기, Shift + 이동: 스태미나를 쓰는 달리기
- E: 교문 사용 → 가까운 문 → 조사/줍기 순서. F: 문과 겹친 조사/줍기
- 계단으로 걸어 들어가기: 자동 층 이동
- I / 인벤토리 버튼: 낱개9칸 가방과 별도 착용1칸. 사용·착용·해제·내려놓기 버튼 제공
- Tab: 현재 공간 안내도. Esc: 가방 닫기 또는 일시정지
- 추적자 ON/OFF: 개발 중 추격·감지·잡힘·추격음·워치 경고를 함께 켜거나 끔. 새 판에도 설정 유지
- 잡힘/성공/정지 화면의 새 판 시작: 새 위치의 아이템으로 다시 시작

열쇠 A·B·C를 모두 모아 **1층 현관 앞 임시 교문에서 E**를 누르면 성공합니다. 매판 열쇠3개는 가구 속과 바닥에 섞어 배치합니다. 책상·교탁·캐비넷·사물함·도서실 책장 등을 조사할 수 있으며 가방이 가득 차면 물건은 남습니다.

## 다운로드와 재생성

`Playable/SchoolEscape-play.html`과 전달용 `SchoolEscape-rooms.html`은 지도·글꼴·텍스처·게임·합성 음향 코드를 포함한 같은 단일HTML입니다. ZIP 다운로드 후 압축을 풀어 Chrome/Edge로 여는 방식은 보조 실행 방법입니다. 관리형 환경에서는 file:// 직접 탐색이 `ERR_BLOCKED_BY_ADMINISTRATOR`로 차단되었으므로 HTTP 실행 검사와 구분합니다.

프로젝트의 `SchoolEscape/`에서:

```bash
node Tools/build_web.cjs /원하는/출력/SchoolEscape-play.html
python3 -m http.server 8791 --directory .
```

개발 서버의 `/Web/`도 실행할 수 있습니다. 빌드 도구는 기본 `/workspace/escape-tools/node_modules/esbuild`를 사용하며 다른 설치는 `ESBUILD_MODULE`로 지정합니다. 배포 HTML 실행에는 Node나 esbuild가 필요 없습니다.

공개 주소는 전용 `school-escape-web` 브랜치에 게시하며 정확한 고정 커밋은 `Deploy/publication.json`에 기록합니다. 주소는 로컬 서버 종료와 무관합니다. 기존 다른 게임의 main·사이트·Pages설정은 변경하지 않습니다. 최종 모델·리깅·텍스처·아이콘·학교 녹음 폴리와 추격 음악은 [교체 목록](ASSETS.md)에 있습니다.

이전0.8 외부 Chromium57항목 통과 기록은 [과거 보고서](Evidence/public-web-items.json)에 보존하며0.9의 검증으로 계산하지 않습니다.
