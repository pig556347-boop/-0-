## 출입·조사와 기존 기능

- 문은 기본 닫힘이며 E로 열고 해당 방으로 이동합니다. 입장 전 내부는 보이지 않고 방 안에서는 현재 방만 표시합니다. 퇴실하면 같은 층의 원래 문 앞에 돌아옵니다. 음악실 연결 예외와 자동 계단은 유지합니다.
- 새 방의 책상·테이블·작업대·보관 상자 몸체, 캐비넷·서가는 기존 E/F 조사에 연결했습니다. 표면 장식마다 조사 지점을 중복 생성하지 않으며 접근 가능한 위치를 사용합니다.
- 아이템 초기 총13개와 A/B/C 개수,9낱개+착용1칸·워치/나침반·소모품·추적자 ON/OFF 및 감지/기억 규칙은 그대로입니다. 새 실내도 같은 층의 랜덤 배치 후보로 쓸 수 있습니다.
- 탈출은 계속1층 현관의 임시 교문에서 A/B/C를 모두 소지하고 E로 실행합니다. 운동장 런타임·실외 추격·최종 교문으로의 탈출 위치 이전은 이번에 구현하지 않았습니다. 옥상·서관·별관 봉쇄도 유지합니다.
