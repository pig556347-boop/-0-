## 추가로 필요한 것

1. 주인공의 사용권이 확인된 2.5D용 리깅 모델 또는 4/8방향 스프라이트와 자연스러운 걷기·달리기 클립. 현 기하 모델은 최종 레퍼런스 품질을 달성한 에셋이 아닙니다.
2. 폐교용 외벽/복도 벽/닫힌 문/창문/계단 모듈과 고유한 낡은 표면 텍스처. 실측 비율은 문 폭 약 1m, 인물 키 약 1.7m 기준입니다.
3. 형광등·배관·학교 표지·게시판·비충돌 소품의 독립 아트. 방 내부 최종 모델도 별도 확보가 필요합니다.
4. 최종 학교 발소리·목재문·계단·환경 폴리와 추격 음악/공간 잔향. 현재 독자 합성 임시 소리가 적용되어 있으며 외부 음원은 확보하지 않았습니다. 전투·괴이 음향은 범위 밖입니다.

어떤 기존 게임의 코드·모델·모션·사운드·기획/설정 파일도 가져오지 않았습니다.
