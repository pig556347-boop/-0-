# 운동장 실행 맵 — 본관에서 실제 교문까지

최신 기록: 2026-10-25. **운동장 탈출 베타0.10**, 지도 revision `playground-gate-2026-10-24` 기준이다. [운동장 기획 1안](PLAYGROUND_PLAN.md)은0.9 당시의 제안과 범위를 보존한 문서이며, 현재 연결·열쇠 배치·탈출 위치는 이 문서와 실행 데이터가 기준이다.

본관 1층 현관에서 **E로 운동장에 나가고**, 북쪽 현관에서 E로 돌아온다. 최종 탈출은 운동장 남쪽의 실제 교문에서 A·B·C를 모두 소지하고 E를 눌러 진행한다. 본관 1층 현관은 외부 연결 문으로 바뀌었다. 본관 53개 방과 기존 2층 연결 통로 봉쇄는 유지하며, 별관·서관·경비초소 내부는 새 공간으로 열지 않았다.

## 고정 배치와 크기

운동장은 69×55칸의 독립 공간이며, 기존과 같은 **1칸 1.25m**를 쓴다. 바깥 경계 한 줄을 제외한 내부 크기는 약 **83.75×66.25m**다. 좌표의 y가 커지는 쪽이 북쪽이다. 건물과 실외는 한꺼번에 렌더링하지 않고, 현재 공간 하나만 표시한다.

| 위치 | 실행 좌표 | 역할 |
|---|---|---|
| 본관 1층 현관 | `floor-1 (24,1)` | E로 운동장 진입, 귀환 착지는 `(24,3)` |
| 운동장 북쪽 현관 | `playground (34,53)` | 본관 귀환 문, 운동장 진입 착지는 `(34,50)` |
| 중앙 차폐 화단 A / B | `(31,31)` / `(37,21)` | 각각 8×3m, 불투명 안내판과 함께 엇갈린 우회 구간 구성 |
| 서쪽 / 동쪽 큰 길 | 대략 `x=10` / `x=58` | 양옆 탐색 구역과 남북 연결 |
| 실제 교문 구조물 | `(34,1)` | 닫힌 철제 교문·기둥·A/B/C 자물쇠 |
| 교문 E 사용 지점 | `(34,3)` | 교문 앞 1.7m 범위에서 열쇠 확인·탈출 |

현관 앞 도착 공간은 넓게 비우고 구령대와 안내판을 좌우로 밀었다. 중앙에는 큰 차폐물 두 개만 두며, 낮은 트랙 표시와 구기장 선에는 충돌을 넣지 않았다. 골대의 가는 그물도 장식으로 처리해 보이지 않는 벽을 만들지 않는다. 나무는 외곽에 두고 수관을 낮게 다듬어 주요 길과 캐릭터를 덮는 정도를 줄였다.

서쪽에는 벤치와 보관함, 동쪽에는 급수대·자전거 거치대가 있어 모양으로 방향을 구별할 수 있다. 남동쪽 경비초소는 닫힌 외부 구조물이다. 남쪽 울타리는 교문 기둥까지 이어져, 교문 옆에 통과할 수 있을 듯한 큰 틈이 보이지 않게 했다. 현재 운동장에는 장식까지 **379개 fixture**가 있고, 그중 충돌 부품은104개이며 탐색 지점은20곳이다. 이 숫자는 개별 나뭇잎·선·손잡이까지 세는 데이터 개수이며 별도 방 개수가 아니다.

## 화면과 길 식별

웹에서는 북쪽 현관의 조명1개와 남쪽 교문의 따뜻한 조명2개가 주변을 실제로 밝힌다. 운동장 미니맵은 축소 상태에서도 충돌 장애물을 표시하고 **북 ↑**와 본관 입구·교문 범례를 보여 준다. 확대하면 입구 이름도 읽을 수 있다. 왼쪽 공간 설명과 열쇠 진행 표시의 세로 간격도 조정했다. 실제 데스크톱 브라우저 검사에서 설명 하단133px, 열쇠 표시 상단148px로 겹치지 않았다.

흙바닥은 웹과 Unity 모두16×13회 반복하도록 설정해 운동장 전체에 텍스처 한 장이 늘어나는 표현을 줄였다. 이는 코드에 적용한 값이며 Unity 화면에서 최종 질감을 확인했다는 뜻은 아니다. [현관 도착 화면](Evidence/playground-north-arrival.png), [중앙 동선](Evidence/playground-central.png), [남쪽 교문](Evidence/playground-gate.png)은 실제 브라우저 실행에서 저장했다.

## 탐색·추격 동선

중앙, 서쪽, 동쪽의 세 경로와 남북 가로 연결을 유지한다. 중앙 경로는 두 화단의 서로 다른 쪽을 돌아 교문 앞으로 간다. 양옆 경로는 주변 보관함을 살피면서 크게 돌아가는 탐색 길로 두었다. 모든 경로 지점은 도착 지점에서 이어지고, 각 직선 구간은 실제 브라우저 이동 판정의 캐릭터 반지름을 포함해 통과 가능하다.

| 고정 경로 | 현관 착지 → 교문 앞 `(34,5)`의 경유점 거리 |
|---|---:|
| 중앙 차폐 우회 | 약 67.46m |
| 서쪽 큰 우회 | 116.25m |
| 동쪽 큰 우회 | 116.25m |

위 값은 지정 경유점을 잇는 길이로 실제 플레이 시간이나 최단 경로가 아니다. `(34,5)`에서 교문 E 사용 중심까지는 2.5m가 더 있다. 생산용 브라우저 커널의 상하좌우 격자 탐색으로 현관 착지에서 교문 사용 중심까지 찾은 최단 길이는 63.75m였으며, 걷기 2.6m/s로 거리만 환산하면 약 24.5초다. 실제 이동은 방향 선택·스태미나·조사·추격에 따라 달라진다.

추적자는 기존 시야·소리·마지막 단서와 관찰한 출입 규칙으로 이 공간을 사용한다. 외부라는 이유로 전역 위치를 전달하지 않는다. 중앙 화단은 실제 충돌과 시야 차폐를 제공하지만 숨기 버튼이나 무적 구역은 아니다. 자세한 실행 검증과 Unity 검증 여부는 [검증 기록](VALIDATION.md)에 구분해 남긴다.

## 열쇠와 조작

최초 기획의 실내 열쇠 배치 기본안에서 진행해, **매 실행마다 A/B/C 중 적어도 하나는 본관에, 적어도 하나는 운동장에** 놓는다. 나머지 하나의 구역도 무작위이며 A/B/C 문자와 구역의 대응을 섞는다. 세 열쇠에는 가구 속 숨김과 바닥 배치가 매판 함께 포함된다. 열쇠 배치와 조사 접근 지점은 통행 가능한 곳을 사용하고 출입·착지·계단·교문 사용 지점에서 최소4m 떨어진다. 가구 속 열쇠는 몸체 중심과 모든 조사 접근점에 이 거리를 적용한다.

운동장의 벤치 아래 수납함·물품 보관함·체육용품 상자·초소 옆 수납함 등15곳은 실제 조사 대상이며, 본관을 포함한 전체 조사 지점은1,108곳이다. 초기 아이템13개와 가방9칸·별도 착용1칸은 유지한다. 바닥 열쇠 줍기, 조사, 내려놓기, 워치 착용은 같은 규칙을 쓴다. 나침반은 선택된 미획득 열쇠 하나를 안내하며 다른 공간에 있으면 본관↔운동장 현관을 포함한 연결 문·계단으로 안내한다. 해당 열쇠를 얻으면 소멸한다. 자세한 효과와 조작은 [아이템 규칙](ITEMS.md)을 따른다.

## 제작 자료와 재생성

배치와 기하 소품은 이 프로젝트의 [기획도](PlaygroundPlan.svg)와 기존 가구 표현을 바탕으로 직접 작성했다. [맵 생성기](../Tools/outdoor_map.py)는 고정 배치를 만들고 [본관 생성기](../Tools/author_maps.py)가 현관 연결과 실제 탈출 지점을 기록한다. 다른 게임의 코드·배치·에셋을 가져오지 않는다.

흙바닥은 [텍스처 생성기](../Tools/prepare_art.py)의 자체 절차 생성 `YardTexture.png`를 사용한다. 울타리·화단·급수대·골대·본관 외벽·경비초소는 기본 기하 도형으로 만든 현재 표현이다. 전문 외부 모델·녹음 효과음·최종 미술 에셋으로 교체되었다고 보지 않는다. 한국어 글꼴 출처와 라이선스는 [FontLicense.txt](FontLicense.txt)에 있다.

```sh
python3 Tools/author_maps.py
python3 Tools/prepare_art.py
python3 Tools/check_maps.py
node Tools/build_web.cjs
```

맵 생성은 제작 시 실행하는 작업이며 플레이 도중 지형을 무작위 생성하지 않는다. 재생성 뒤에는 현관 왕복, 세 경로·탐색 지점 이동, 열쇠 분포, 실제 남쪽 교문 탈출을 [운동장 브라우저 검증기](../Tools/playground_browser_check.cjs)로 확인한다. 공개 주소의 별도 실행 검증에는 [배포 검증기](../Deploy/verify-web.mjs)를 사용한다.
