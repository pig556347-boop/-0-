# 열쇠·조사·수납 — 운동장 탈출 베타 0.10

2026-10-24 사용자가 인벤토리·조사·랜덤 아이템·열쇠 탈출과 개발용 추적자 ON/OFF를 요청했고, 초코바100% 회복·시계 부품 명칭 유지·열쇠3개 동시 사용·9낱개+별도 착용1칸 기본안을 확인했다. 최초 탐방의 아이템/랜덤 생성 제외 조건은 이 요청 범위에서 변경한다. 맵 배치 자체를 무작위 생성하거나 다른 게임의 코드·에셋을 사용하지 않는다.

아래는 0.10 현재 규칙이다. 0.8의 층별 열쇠1개와1층 현관 임시 교문 규칙은 운동장 구현으로 변경했다. 당시 기록은 [결정 이력](DECISIONS.md)과 [작업 기록](WORKLOG.md)에 보존한다.

## 조작과 성공 조건

- E: 교문 사용 → 가까운 문 → 조사/줍기 순서로 대상 선택. 출입문과 조사 대상이 겹치면 F로 조사/줍기만 할 수 있다. 문 앞에서 조사 때문에 방을 나가지 못하거나 내려놓은 아이템을 영구히 회수하지 못하는 상황을 막는다.
- I 또는 인벤토리 버튼: 3×3 가방 9칸. 같은 아이템도 낱개로 한 칸을 사용한다. 착용은 가방과 별도의1칸이며 현재는 스마트워치가 들어간다.
- 가방의 사용·착용·해제·내려놓기 버튼으로 관리한다. 가방이 가득 찼을 때는 새 물건을 삭제하지 않고 남겨두며, 착용 해제도 가방 빈칸이 있어야 가능하다.
- 가방을 여는 동안 이동·추적자·회복/버프 시간·소리를 함께 정지한다. 닫으면 이어간다. Esc 일반 정지와 포커스 이탈 정지는 별도로 유지한다.
- 열쇠 A/B/C를 모두 가방에 소지한 뒤 **운동장 남쪽 교문 사용 지점 `(34,3)`의1.7m 안**에서 E를 누르면 세 열쇠를 함께 사용하고 탈출 성공을 표시한다. 부족하면 필요한 문자를 알려준다. 본관1층 현관의 E는 운동장으로 나가는 문이며, 열쇠3개가 있어도 그곳에서 탈출하거나 열쇠를 소모하지 않는다.
- 새 판 시작은 모든 아이템/조사 상태/스태미나/탈출/AI 기억을 초기화하고 새 시드를 선택한다. 추적자 ON/OFF 개발 설정은 유지한다.

## 매판 배치

초기 총13개: 열쇠 A/B/C 각1개, 비타민워터3개, 초코바3개, 시계초침/시계분침/시계본체 각1개, 스마트워치1개.

열쇠는 **본관에 최소1개, 운동장에 최소1개**를 배치하고 나머지1개의 구역은 시드로 정한다. A/B/C의 구역 배정도 섞으므로 운동장 열쇠 문자가 고정되지 않는다. 매판 세 열쇠에 바닥 배치와 가구 속 숨김을 모두 포함한다. 본관의 층·방, 운동장 가구와 정확한 위치도 시드에 따라 달라진다. 지도 자체와2층후보1 구조는 고정이다.

열쇠는 실제 이동으로 닿을 수 있는 위치를 사용하고 문 사용·공간 착지·계단·남쪽 교문 사용 중심에서 **최소4m** 떨어뜨린다. 가구 속 열쇠도 가구 중심과 조사 접근점이 이 간격을 만족해야 한다. 비타민워터와 초코바는 본관 각층1개씩, 시계 부품은 세 층에 나눠 배치하며 스마트워치는1층 후보에서 고른다.

가구 조사는 책상·교탁·사물함·캐비넷·도서실 책장·작업대 등의 주요 몸체를 대상으로 한다. 운동장에서는 벤치 아래 수납함·물품 보관함·체육용품 상자·초소 옆 수납함도 조사할 수 있다. 전체 조사 지점은1,108곳이며 그중15곳이 운동장에 있다. 빈 곳도 있고, 접근 위치가 막히거나 다른 벽 너머인 가구에서는 상호작용하지 않는다. 조사하면 한 번 발견된 물건을 획득하고 같은 가구에서 반복 생성하지 않는다. 가득 찬 가방 때문에 못 가져간 물건은 발견 상태로 남는다. 내려놓으면 현재 공간에 하나의 동일 UID로 배치하고 이전 가구에는 남기지 않는다.

## 추적자 개발 설정과 감지

화면의 **추적자 ON/OFF**는 이동·시야/소리 감지·잡힘·추격 음악·워치 근접 반응을 함께 제어한다. OFF로도 조사와 탈출을 시험할 수 있다. ON은 지정 안전 지점에서 배회를 시작한다.

스폰 후보는 본관3개 층과 운동장의 지정 안전 지점을 사용하며 벽/가구/출입·계단 진입부를 피한다. 같은 공간에 플레이어가 있으면15m 이상 떨어진 안전 후보만 쓴다. 배회는 플레이어 좌표와 독립적으로 관심 지점과 문·계단을 이동하며1~3초 머무른다. 운동장 현관도 관찰한 출입 단서가 있을 때 지연 추적하며, 다른 공간으로 갔다는 이유만으로 현재 위치를 전역 감지하지 않는다.

시야11m/전방120도와1.8m 주변 감지에 가림 검사를 적용한다. 달리기8m·걷기2m·문6m·조사4m 소리는 발생한 순간의 위치를 조사하게 한다. 가림과 연결 경로를 고려하며 다른 공간의 현재 플레이어 좌표를 그대로 읽지 않는다. 직접 보았을 때 추격하며, 마지막 감지 위치 도착 또는8초 새 단서가 없으면4초 수색, 총12초 무감지 또는3초 경로 불가 시 배회로 복귀한다. 문/계단 이동도 최근 출입 단서를 인지한 경우에만 따라간다.

[실제 읽은 공개 사례와 적용 이유](PURSUIT_RESEARCH.md). 위 수치는 다른 게임의 비공개 상수를 복사한 값이 아니라 폐교탈출 기본안이다.
