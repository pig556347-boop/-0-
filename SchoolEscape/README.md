## Unity에서 실행

1. Unity Hub로 **Unity 6000.0.62f1 LTS**를 설치하고 이 폴더를 추가합니다. 브라우저 빌드에는 해당 버전의 WebGL Build Support도 설치합니다.
2. `Assets/Scenes/Exploration.unity`를 엽니다. 또는 `School Escape > Open exploration`을 선택합니다.
3. Play 후 **탐방 시작**을 누릅니다. 다른 프로젝트의 씬·코드·에셋을 추가할 필요가 없습니다.
4. **WASD / 방향키:** 걷기, **Shift + 이동:** 달리기, **E:** 문/가구 조사/줍기/교문 사용, **F:** 문과 겹친 조사·줍기, **I:** 인벤토리, **계단 진입:** 자동 층 이동, **Tab:** 안내도, **Esc:** 가방 닫기 또는 일시정지. 개발용 **추적자 ON/OFF**와 음량 조절을 제공합니다.
5. `School Escape > Build separate WebGL`은 이 프로젝트의 `Builds/WebGL`에만 출력합니다. 기존 배포를 게시하거나 교체하는 명령은 없습니다.

계단은 E키 없이 발판에 진입하면 이동합니다. 도착 직후에는 도착한 계단 주변 3.2m 구역을 한 번 벗어나야 재진입할 수 있고, 최소 0.75초 전환 간격도 적용합니다. 방문은 기본 닫힘입니다. 제작된 방 앞에서 E를 누르면 문이 열리는 동안 잠깐 멈춘 뒤 독립 방에 입장합니다. 나갈 때도 출입문 앞에서 E를 누릅니다. 복귀 위치는 원래 층의 문 앞이며, 재방문 시 문은 다시 닫혀 있습니다. 본관에 표기된53개 방은 모두 해당 실내와 연결했습니다. 옥상·서관·별관 진입은 계속 봉쇄합니다.

## 독립 브라우저 검토판

Unity 설치를 기다리는 동안 평면 배치·동선·가시성을 확인하는 별도 Three.js 구현입니다. **Unity WebGL 결과물이 아닙니다.** Unity와 동일한 `Assets/Resources/SchoolMap.json` 및 새로 만든 표면 텍스처를 읽습니다.

이 폴더에서 실행:

```bash
python3 -m http.server 8791 --directory .
```

브라우저에서 서버의 `/Web/` 경로를 엽니다. 필요한 라이브러리는 `Web/vendor`에 포함되어 있어 외부 CDN 연결이 필요하지 않습니다. 데스크톱 키보드 조작을 기준으로 합니다.

## 범위와 구조

- 본관 1층: 현관·중앙홀·방송실 주변 우회·복도 끝·빈교실3과 교직원 화장실 사이 주 계단.
- 본관 2층: 문서의 **후보 1**. 최신 손그림에 따라 빈교실A/학생화장실 앞은 폭4셀의L자 복도입니다. 막힌 중앙 섬과 우회 복도. 서관/별관 방향에 각각 약37.5m/38.75m 연결 통로가 있고 끝에서 봉쇄.
- 본관 3층: 외곽 복도와 중앙 굴절·분기·벽 섬·막다른 통로. 옥상 연결부 봉쇄.
- 19개 교실 모듈, 음악실, 미술실과 창고, 2층 도서실, 보건실, 행정실, 컴퓨터실, 2/3층 교무실, 방송실과12개 화장실을 독립 맵으로 제작·확대했습니다. 복도에서 내부가 보이지 않고 방 안에서는 해당 방만 표시합니다.
- 남은 본관12개 방에 용도별 가구·중앙/측면 우회로·85개 추가 탐방 지점을 제작했습니다. 기존41개 실내 데이터와 복도·계단·봉쇄부는 그대로 유지했습니다.
- 운동장은69×55셀, 내부 영역 약83.75×66.25m의 독립 공간입니다. 북쪽 본관 현관→중앙/좌우 우회로→남쪽 실제 교문을 연결하고, 엇갈린 차폐 화단2곳·골대·구령대·벤치·물품함·급수대·닫힌 초소를 배치했습니다. 골대 그물은 장식이며 최종 탈출은 남쪽 교문에서만 작동합니다.
- 운동장 바닥은 새로 만든 흙 텍스처를 반복하고 교문은 따뜻한 조명, 본관 출입문은 차가운 조명으로 표시합니다. 브라우저 안내도는 운동장 장애물과 북쪽/본관 입구/교문을 표시합니다. 배치·조명은 현재 임시 기하 아트이며 최종 모델·학교 폴리는 [교체 목록](Docs/ASSETS.md)에 남깁니다.
- 음악실의 메인실→연결 통로→보컬 연습실/악기창고만 한 공간으로 이어집니다. 미술실 창고도 별도 문/독립 맵으로 이동합니다. 도서실은 백업의 초안입니다. 음악실은 메인실 옆의 꺾인 통로 끝 보컬룸과 통로 중간 악기창고가 있는 비정형 구조입니다.
- 도서관 책장을 속이 채워진 몸체에서 뒷판·옆판·선반으로 바꾸고 책과 면을 분리했습니다. 책의 그림자를 조정해 반짝임을 줄였습니다.
- 교실 뒤에는 큰 칸의4열×2행 사물함 모듈4개를 정렬했고, 방마다 수납장·교구·가구·책상 소품을 보강했습니다.
- 사용자 후속 요청으로 당직자 추격·스태미나·음향, 아이템·조사·열쇠 탈출을 추가했습니다. 매판 아이템 위치와 지정 후보 스폰은 달라지지만 지도 자체는 고정입니다. 전투·공격·점프·회피·숨기·괴이·구출은 없습니다.
- `Assets/Scripts`: 독립 Unity 런타임과 명시적으로 실행하는 Unity 검증 러너.
- `Tools/author_maps.py`: 수작업으로 정한 고정 지도 데이터 재생성. 플레이 중 무작위 생성이 아닙니다.
- `Tools/outdoor_map.py`: 독립 운동장과 현관/교문·외부 소품 배치 작성.
- `Tools/check_maps.py`: 정적 연결성·문 앞 도달·층간 도착지·방 겹침 검사 및 층별 SVG 출력.
- `Tools/prepare_art.py`: 새 표면 텍스처와 OFL 한글 글꼴 부분집합 제작. 일반 플레이에는 실행할 필요가 없습니다.
- `Docs/Floor1.svg` ~ `Floor3.svg`: 런타임과 동일한 지도 데이터의 안내도.

검증 러너 사용과 제한은 [VALIDATION.md](Docs/VALIDATION.md)를 확인하세요. 에셋 구분과 교체 대상은 [ASSETS.md](Docs/ASSETS.md)에 있습니다.
