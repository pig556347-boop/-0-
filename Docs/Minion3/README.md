# 잔몹3 적용

제공된 15개 분할 볼륨을 복원했다. 기본 FBX는 정적 메시지만 모션 FBX에는 같은 학생 스킨(원본 정점 24,992개·삼각형 50,000개), 41개 뼈와 34개 가중치 그룹이 포함되어 이 원본 스킨을 사용한다. UV와 상위 네 정점 가중치를 보존하고 기본 색상은 게임용 2K로 정리했다.

두 펀치의 63프레임 전체 뼈 위치·회전이 수치상 완전히 동일한 왼손 펀치인 것을 확인했다. 첫 타는 제공한 왼손 펀치를 쓰고, 두 번째는 그 동작의 뼈 이름을 좌우로 교환하고 회전을 대칭 변환한 오른손 펀치를 쓴다. 이후 무작위 손 선택은 기존 전투 규칙을 따른다. 새로 만든 임의의 관절 모션을 섞지 않았다. 변환 후 타격 자세 팔꿈치는 왼손 약 142도·오른손 약 141도다.

걷기는 새로 제공된 잔몹3 Walking을 직접 쓰고, 강공격은 제공된 Kicking을 사용한다. 준비·피격·방어는 기존 제공 모션을 연결한다. 일반 캠페인 적은 잔몹1·2·3 순으로 생성한다. 기존 공격 간격·준비·회수 시간과 카메라 확대 설정을 유지했다.

Blender에서 네 모션을 11개 구간과 21개 구간으로 각각 재검토했다. 각 변형 메시의 유한 좌표와 크기 범위를 확인했으며 결과는 `offline-audit.json`에 있다. `source-*.png`는 Blender 사전 검사 이미지다. Unity에서는 세 모델의 스킨·모션·실제 AI 피해·피격·사망·복구, 네 모서리 카메라, 캠페인 혼합 생성과 후기 시체 정리를 검사한다. 실행 결과는 검증 완료 후 기록한다.
