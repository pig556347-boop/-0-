# 임시 테스트 단축키

게임 시작을 누른 뒤 플레이 화면을 클릭하고 키보드 위쪽 숫자키를 사용한다. 로비에서는 작동하지 않으며 Esc 일시정지 중에는 무시한다.

| 키 | 이동 |
| --- | --- |
| 1 | 오프닝·튜토리얼·덩치 연습전을 건너뛰고 1-1 실전 시작 |
| 2 | 1-5 마지막 라운드 도재학 보스전 |
| 3 | 1-10 마지막 라운드 한승빈 보스전 |
| 4 | 1-11 마지막 라운드 황빈 보스전 |

전환하면 튜토리얼 코루틴·입력 제한·수면 자세·오프닝 소품과 덩치 대결 업데이트를 정리하고, 기존 적·시체를 제거한 뒤 실제 캠페인 생성 경로로 해당 라운드를 시작한다. 플레이어는 체력을 회복하고 진행 중 공격을 취소한다. 게임 오버나 캠페인 완료 화면에서도 다시 테스트할 수 있다. 기존 전투 수치와 모션 속도는 변경하지 않는다.

**정식 출시에서는 반드시 `KICKBACK_RELEASE` 스크립팅 정의를 추가한다.** `TestCombatShortcuts.Enabled`가 false가 되어 입력 처리·화면 안내 설치·스테이지 점프 진입점이 모두 비활성화된다. 임시 단축키 구현과 부트스트랩 설치 호출은 정식 출시 정리 시 삭제 대상으로 표시했다. 출시 빌드를 만들 때 이 정의를 빠뜨리지 않는다.

검사 장면은 실제 브라우저 숫자키로 오프닝 중 스킵, 세 보스 이동, 궁극기·보스 공격 중 전환, 이전 시체 정리, 일시정지 중 무시, 플레이어 사망 후 복귀를 확인한다. 실행 완료 후 결과를 기록한다.
