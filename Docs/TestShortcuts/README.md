# 임시 테스트 단축키

게임 시작을 누른 뒤 플레이 화면을 클릭하고 키보드 위쪽 숫자키를 사용한다. 로비에서는 작동하지 않으며 Esc 일시정지 중에는 무시한다.

| 키 | 이동 |
| --- | --- |
| 1 | 오프닝·튜토리얼·덩치 연습전을 건너뛰고 1-1 실전 시작 |
| 2 | 1-5 마지막 라운드 도재학 보스전 |
| 3 | 1-10 마지막 라운드 한승빈 보스전 |
| 4 | 1-11 마지막 라운드 황빈 보스전 |

전환하면 튜토리얼 코루틴·입력 제한·수면 자세·오프닝 소품과 덩치 대결 업데이트를 정리하고, 기존 적·시체를 제거한 뒤 실제 캠페인 생성 경로로 해당 라운드를 시작한다. 플레이어는 체력을 회복하고 진행 중 공격을 취소한다. 게임 오버나 캠페인 완료 화면에서도 다시 테스트할 수 있다. 기존 전투 수치와 모션 속도는 변경하지 않는다.

**정식 출시에서는 반드시 `KICKBACK_RELEASE` 스크립팅 정의를 추가한다.** `TestCombatShortcuts.Enabled`가 false가 되어 입력 처리·화면 안내 설치·스테이지 점프 진입점이 모두 비활성화된다. 임시 단축키 구현과 부트스트랩 설치 호출은 정식 출시 정리 시 삭제 대상으로 표시했다. 출시 빌드를 만들 때 이 정의를 빠뜨리지 않는다.

검사 장면은 실제 브라우저 숫자키로 오프닝 중 스킵, 세 보스 이동, 궁극기·보스 공격 중 전환, 이전 시체 정리, 일시정지 중 무시, 플레이어 사망 후 복귀를 확인한다. 최종 실행 결과는 아래에 기록했다.


## 최종 실행 결과

검증 소스 `af4630b98`. [Unity 빌드·실제 브라우저 검사·배포](https://github.com/pig556347-boop/-0-/actions/runs/38981277361).

- 실제 브라우저 숫자키를 사용하는 전환 검사 29개 통과 (`shortcuts.json`). 오프닝 중 스킵·1-5/1-10/1-11 직접 입장·진행 중 궁극기 취소·기존 보스 공격과 시체 정리·일시정지 중 무시·사망 뒤 복귀를 확인했다.
- 도재학 32,230개, 잔몹1~4 각각 31,777 / 32,544 / 32,852 / 32,648개 검사 통과. 가중치·스킨의 정점별 검사도 포함한 수치다.
- 실제 캠페인 생성·전환과 후기 시체 정리 106개, 기존 펀치 612개, 시체 접지·복구 42개 검사 통과. HUD 네 해상도 각 412개, 기존 제공 모션 두 차례 각 623개, 로비·튜토리얼 입력 제한·음악 정지/재개 검사도 통과했다. 감지한 런타임 오류 배열은 비어 있다 (`summary.json`).
- 출시 정의의 양쪽 분기를 포함한 C# 2,048개 파일/조건 구문 검사, 브라우저 JS 구문과 공백 검사 통과. 실제 Unity WebGL 빌드와 GitHub Pages 배포도 성공했다. `KICKBACK_RELEASE`를 켠 별도 Unity 배포 빌드는 이번 범위에 포함하지 않는다.

모든 결과 JSON의 소스 커밋을 대조하고 [실제 단축키 안내 화면](test-shortcuts.png)을 확인했다. 수동 전체 캠페인 완주를 뜻하지 않는다. 검증 기록 커밋은 문서와 증거 파일만 추가한다.

정식 출시에서 완전히 삭제할 때는 `TestCombatShortcuts`, 부트스트랩 설치 호출, `EncounterDirector.JumpForTesting`, `TutorialDirector.SkipForTesting`, 숫자키 변환과 안내를 정리한다. 전용 검사도 단축키 미설치·점프 거부를 확인하는 출시 검사로 전환한다.
