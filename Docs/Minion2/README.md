# 잔몹2와 전투 화면 확대

제공한 24개 분할 파일을 모두 복원했다. `20M`과 기본 모델 압축은 동일하다. 기본 FBX는 스킨이 없지만 새 모델의 MMA 킥과 사이드 킥에는 41개 뼈·34개 가중치 그룹이 있어 이 스킨을 사용한다. 원본 정점 24,962개·삼각형 50,000개·UV·상위 네 스킨 가중치를 보존하고 기본 색상을 게임용 2K로 정리했다.

새 모델용 MMA 킥·사이드 킥을 직접 사용한다. 함께 제공된 펀치 두 개와 Kicking은 잔몹1 스킨을 포함하므로 41개 뼈대에 회전을 연결했다. 이동·준비·피격·방어는 기존 제공 모션을 사용한다. 새 모델로 옮긴 타격 시 팔꿈치는 오른손 약 168도, 왼손 약 138도이다. 소스와 뼈대 차이를 무시해 완전 신전이라고 주장하지 않는다.

일반 캠페인 적을 잔몹1·잔몹2 순서로 번갈아 생성한다. 두 모델의 모션 라이브러리를 각각 보관해 서로 바뀌지 않도록 한다. 펀치는 기존 왼손→오른손→이후 무작위 순서, 잔몹2 강공격은 MMA 킥→Kicking→사이드 킥 순서다. 공격 간격·준비·회수·타격 판정 시간은 기존 캠페인 설정을 유지했다. 기존 잔몹1의 두 발차기 순서도 유지한다.

카메라의 기본 직교 크기를 9.4에서 7.5로 줄여 16:9에서 약 25% 크게 보이게 한다. 4:3은 가로 폭을 보호해 9.375를 사용한다. 중앙에서는 고정되고, 화면 가장자리로 이동할 때만 교실 안에서 제한적으로 부드럽게 보정한다. 시선 회전이나 점프 높이에는 반응하지 않는다. 이는 확대 후 가장자리에서 주인공이 잘리는 것을 막기 위한 기본 선택이다.

검증: Blender에서 각 공격 11개 구간의 실제 스킨 정점, Unity 브라우저에서 두 모델의 모션·실제 AI 타격·피격·사망·복구·혼합 생성·카메라 두 화면 비율과 네 모서리 및 기존 전체 회귀 검사를 실행한다. 현재 소스의 실행 결과는 아래 기록에 남긴다.
