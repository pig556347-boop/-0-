# 전투·교실 시각 개선

원본 캐릭터·교실 모델, 텍스처 UV, 카메라의 가까운 고정 프레이밍과 경계 보정은 유지한다. 전투 수치나 충돌체에는 영향을 주지 않는다.

- 일반 주먹/발차기, 강공격, 궁극기 중간타/마무리의 방향성 충격선 크기·수명·색을 구분했다. 일반 타격은 0.16초, 궁극기 마무리는 0.24초 동안 빠르게 감쇠한다. 구형 붉은 파티클과 캐릭터를 가리는 붉은 캡슐 잔상은 제거했다.
- 가드는 청색 방어 링, 패링은 금색 방어 링, 가드 파괴는 짧은 청색 파편으로 표시한다. 회피는 신발 높이의 짧은 회색 이동 흔적이다. 기존 `Damaged`, `GuardBroken`, `Dodged` 이벤트로 구동하며, NPC에도 동일하게 적용한다.
- 히트스톱은 주먹 약 27ms, 일반 발차기 약 38ms, 강공격 약 52ms, 궁극기 중간타 12ms/마무리 약 68ms로 차등 적용한다. NPC 공격의 히트스톱은 해당 값의 80%다. 최대 약 8cm의 짧은 감쇠 카메라 진동은 화면 평면에서만 발생한다. 패링은 60ms이다. 카메라 줌·앵글 변경은 없다.
- 이펙트는 별도 `System.Random`을 사용해 AI/게임플레이 난수 소비에 간섭하지 않는다. 메시·머티리얼·게임오브젝트를 소유 컴포넌트와 함께 정리한다. 일시정지와 히트스톱 중에는 시각 이펙트도 멈춘다.
- 플레이어/NPC의 발 아래 부드러운 접지 그림자를 추가했다. 점프 높이에 따라 약해지고 넓어지며, 사망 시 더 낮고 넓게 표시한다. 그림자는 렌더링만 담당하고 활성 충돌체를 두지 않는다.
- 캐릭터는 기존 UV/질감을 유지하면서 넓고 연속적인 명암, 약한 윤곽 보조광, 0.11초의 은은한 피격색을 사용한다. 교실·책상은 이중 면 렌더링과 좁은 연속 명암을 유지하여 삼각형 얼룩이 다시 생기지 않도록 했다.
- 교실 벽 가장자리의 몰딩·조명·시계·게시판과 창가 바닥의 매우 약한 채광 띠를 추가했다. 전투 중앙에는 추가 장식·충돌체를 두지 않는다. 보스 매트는 중성색과 얇은 테두리·코너 표시로 가독성을 보완했다.
- WebGL 비용을 제한하기 위해 그림자는 작은 단일 쿼드, 타격은 단일 짧은 메시, 배경 디테일은 단순 공유 재질로 구성했다. 실시간 고해상도 그림자·후처리·전체 화면 섬광은 추가하지 않았다.

## WebGL 최초 실행 예외 수정

CI 39028358344에서 최초 시각 피드백 두 개의 초기화 중 네이티브 null 예외가 발생했다. 접지 그림자와 창가 채광은 `CreatePrimitive(Quad)`가 만드는 MeshCollider를 요구하지 않는 시각 메시이므로, 명시적 MeshFilter/MeshRenderer+4정점 UV 메시로 대체했다. 해당 경로는 이제 Collider 조회·생성에 의존하지 않는다. 메시 크기·UV·재질·기존 화면 배치는 동일하며, 각 소유 컴포넌트가 동적 메시도 해제한다. Cube/Cylinder 장식은 기존 경로를 유지한다.
