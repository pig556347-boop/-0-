# 전투·연출 통합 밸런스

도재학이 춤추듯 보이던 Quad Punch·Kicking·Roundhouse Kick를 실전에서 제거했다. 원본 파일과 미리보기는 보존하지만 전투 API에서도 거부한다. 실제 사용 다섯 공격은 불필요한 앞뒤 프레임을 잘라 원래 속도에 가깝게 연결한다. 원투→MMA, 옆차기→훅, 짧은 돌진→옆차기, 훅→원투의 네 연계를 거리·방어·회복 상태에 따라 선택한다.

J·I는 최대3타와 말미 입력 예약, K는 시작 간격1.85초, 공통 공격 간격으로 무한 예약·키 교대 취소를 막는다. 가드량과 패링 재시도, 회피 재사용을 조정하고 준비 상태를 HUD로 표시한다. 플레이어와 1-1~1-5 잔몹·도재학을 같이 조정했으며, 1-10·1-11 보스의 고유 수치는 유지했다. 기존 임시 테스트 숫자키1~4도 유지한다.

다른 게임은 공개 소스의 동작 회수·방어 재사용·AI 거리/시야 재검사·동료 분리 원칙을 참고했다. 외부 상용 게임을 직접 플레이하거나 접근이 막힌 자료를 읽었다고 주장하지 않는다. 제시한 수치는 이 게임을 위한 첫 통합 설계이며 이후 실제 플레이 피드백으로 조정할 수 있다.

검증은 실제 Unity WebGL에서 피해·입력 난발·공통 회수·회피/패링/가드 파괴·다중 대상 게이지·공격 중단·AI 연계/증원·시체·일시정지·로비·사운드까지 수행한다. Balance·HUD 호환성·원본 모션의 짧은 포즈 검사에서는 소프트웨어 렌더링이 접촉 구간을 건너뛰지 않도록 프레임당 최대 게임 시간 .05초를 사용한다. 발차기 자세는 실제 타격 이벤트가 발생한 프레임의 LateUpdate 뒤에 검사한다. 실제 키 반복은 고정 실시간 대신 러너가 게임 시간의 검사 종료를 알릴 때까지 입력하며, 실제 튜토리얼 조작은 읽기 전용 게임 시계와 회수 완료 상태를 보고 진행한다. 이 보정은 별도 검사 장면에만 적용되며 실제 플레이 설정을 변경하지 않는다. 최종 실행 결과와 배포 기록은 아래와 같다.
