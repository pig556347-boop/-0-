# 전투 오디오 개선

도재학까지의 전투 피드백을 위해 효과음 15종과 음악 3곡을 새로 직접 합성했다. 외부 녹음·상용 음악·타 게임 효과음은 사용하지 않았다. `Tools/generate_audio.py`로 같은 결과를 재생성할 수 있다.

| 상황 | 적용 |
|---|---|
| I 펀치 | 짧은 공기음 + 마른 접촉음 |
| J 킥 | 넓은 공기음 + 낮은 몸통 접촉음 |
| K 강공격 | 더 낮고 긴 공기음·충격음 |
| Q 궁극기 | 시작 상승음, 연타 접촉음, 마지막 타격 공기음 구분 |
| 가드·패링 | 가드의 둔한 막힘과 패링의 짧은 금속성 확인음 분리 |
| 회피·처치 | 작은 회피 공기음, 처치 시 중복 접촉음 대신 단일 다운 효과 |
| 로비·일반전·도재학 | 90 / 116 / 132 BPM의 별도 오리지널 루프 |

도재학은 생존한 보스 개체를 자동 감지해 전용 음악으로 전환한다. 저음 펄스, 절제된 단조 모티프, 탐 필을 사용한다. 기존 로비·일반전보다 약간 높은 RMS로 마스터링하고 곡 교체 시 짧게 페이드한다. 전용 곡은 16마디·약 29.09초이고, 마지막 잔향은 앞부분으로 감아 루프 끝에서 잘리지 않게 했다.

실제 공격 판정 시점에 공기음을 재생하고, 명중 확인 이벤트에서만 접촉음을 재생한다. 가드·패링에는 일반 명중음을 겹치지 않는다. 타격 시 음악만 잠깐 약 22% 낮춰 피드백을 앞에 둔다. 동일 음원의 35 ms 내 중복을 제한하고 효과음은 최대 6개까지 재생한다. 패링·궁극·다운은 일반 공기음보다 우선한다. 브라우저 효과음 버스에는 압축기와 부드러운 출력 상한을 두고, 일반 Unity 재생에는 동시 음량 여유를 적용한다.

전체·음악·효과음 설정과 저장을 유지한다. Esc 정지 시 음악과 효과음 잔향을 즉시 중지하고, 재개 시 음악의 정지 위치에서 이어간다. 로비 복귀/종료 중 디코드가 끝나는 경우에도 늦은 소리나 오류를 남기지 않는다. 기존 검증 이벤트 `LobbyMusic`, `BattleMusic`, `Whoosh`, `Hit`, `Down`, `Success`는 유지한다.

검사 기록:

- `node Tools/test_audio_mixer.cjs` 통과: 곡 중복 재시작 방지, 보스 곡 선택, 6개 보이스 제한, 우선순위, Esc 정지·위치 보존 재개, 독립 음소거, 종료 중 디코드 취소.
- `node --check < Assets/Plugins/WebGL/KickBackAudio.jslib` 통과.
- WAV 18개 전체 32 kHz / 16-bit PCM 검사 통과. 음악은 스테레오, 효과음은 모노. 최대 원본 피크 0.61, 잘린 샘플 0개, 끝과 시작 간 샘플 차이 0.
- 음악 RMS: 로비 0.05197, 일반전 0.05805, 도재학 0.06491. 파일별 수치는 `Assets/Resources/Audio/audit.json`에 기록.
- 통합 작업 중 C# 구문 검사 2,176개 파일/설정 조합 통과. 실제 Unity/WebGL 컴파일·브라우저 출력·전투 회귀 검사는 전체 변경의 CI에서 별도로 확인한다.

행동 테스트는 모의 Web Audio 객체로 일정과 수명 관리를 검사한다. 실제 스피커의 청감과 최종 브라우저 소리 출력 검증을 대신하지 않는다.
