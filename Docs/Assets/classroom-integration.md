# Supplied classroom scenery

All five individually uploaded ZIPs were received. Originals are kept outside the checkout under `/workspace/asset-import/classroom` and have not been overwritten. Their hashes and dimensions are recorded in `source-inspection.json`.

Runtime copies: FBX meshes and 1024px base-color textures in `Assets/Resources/Classroom`. Mesh budgets: floor 12, wall 3,999, board 4,000, window 6,000, furniture 15,999 triangles. Floor color is baked from the supplied mesh onto a shallow tile to preserve UV details; the side slab has no overlapping top face. Original models had approximately one million vertices each. The furniture is one desk/chair set, not two desks.

The shared visual builder places 126 two-metre floor modules, four rear wall modules, one board, two windows and eight desk/chair sets. Rear-facing scenery uses the existing orthographic camera. Existing floor and arena boundary colliders remain; original blockout renderers are hidden. Classroom prop renderers do not add gameplay colliders. Corridor/boss layouts continue hiding the desk sets.

Inspection PNGs are Blender renders of converted assets, not in-game screenshots. The production screenshot generated by browser tests is the actual Unity WebGL result. CI checks mesh/texture budgets and loading of all five assets, then runs the existing movement, crouch, jump, attack, tutorial and responsive HUD checks before deployment.

This change concerns classroom scenery. Existing combat and character animation logic is unchanged; it does not constitute a new authored sleeping animation.
