# 권민준 모션 적용 현황 — 2026-10-15

사용자가 제공한 20개 FBX의 실제 모션을 기존 권민준 메시·UV·텍스처·리그에 맞춰 사용한다. 임의로 만들었던 공격·이동·앉기·회피·잡기 동작은 실제 게임에서 재생하지 않는다. 원본 후보와 편집용 Blender 파일은 보존한다.

| 역할 | 사용하는 모션 | 동작 |
|---|---|---|
| 전투 준비 | FightingIdle | 기본 가드 자세 |
| 이동 | Walking / Running / WalkingBackwards / LeftStrafe / RightStrafe | 실제 이동 속도와 방향에 따라 재생 |
| 일반공격 1타 | RoundhouseKick | 높은 돌려차기 |
| 일반공격 2타 | MmaKick2 | 낮은 발차기 |
| 일반공격 3타 | MmaKick1 | 제공된 높은 발차기. 기존 임의 뒤후리기를 사용하지 않음 |
| 강공격 | MmaKick1 | 기존 강공격 준비·회복 시간에 맞춰 재생 |
| 궁극기 1단 | MmaKick2 → RoundhouseKick → MmaKick1 | 3연타, 기본 총 피해량 30 |
| 궁극기 2단 | CenterBlock → 위 3연타 | 기존 반격 조건 유지, 기본 총 피해량 48 |
| 궁극기 3단 | 위 3연타를 두 번 | 6연타, 기본 총 피해량 60 |
| 점프 | Jumping1 | 실제 수직 속도에 따라 상승·하강 구간을 연속 재생. 착지 후 준비 자세로 전환 |
| 방어 / 방어 충격 | CenterBlock / RightBlock | 기존 가드·패링 판정에 연결 |
| 약한 / 강한 피격 | HitReaction / ReceivingABigUppercut | 서 있는 피격 상태에 맞춘 구간 사용 |
| 사망 | Stunned | 바닥에 쓰러진 자세 유지 |
| 시작 연출 | Sitting → SitToStand → FightingIdle | 착석·기립 후 튜토리얼 시작. 좌석은 위치 확인용 임시 형태 |
| 앉기·회피·잡기 | FightingIdle | 전용 제공 클립이 없어 준비 자세 유지. 기존 조작·판정은 유지 |

FlyingKick, Jump, Jumping 등 미채택 후보도 원본 검수 대상에 포함한다. 덩치의 기존 임의 애니메이션은 중지되어 있으며, 전용 모션을 연결하기 전까지 정적인 모델로 표시한다.

## 연결과 피드백

- 새 540도 동작을 임의로 만들지 않고 제공된 세 공격 모션의 타격·회수·다음 준비 구간을 연결한다.
- 중간 타격은 넉백을 줄여 연타를 유지하고, 마지막 타격에서 밀어낸다. 플레이어 궁극기의 중간 타격 정지만 최대 0.018초로 줄이며, 일반 공격·마지막 타격·보스 피드백은 기존 설정을 사용한다.
- 일반공격 회수 끝은 제공된 FightingIdle로 보간한다. 3타에도 실제 공격 모션이 재생된다.
- 점프 하강 중 한 자세를 고정하지 않고 연속 재생한다. 시각 모션의 수직 루트 이동을 제거해 물리 점프와 중복되지 않게 한다. 점프 높이·이동 물리는 바꾸지 않는다.
- 별도 시각 컴포넌트 AuthoredPlayerView가 CombatActor의 실제 타격 순서를 읽는다. 애니메이션이 추가 피해 이벤트를 임의로 만들지 않는다.
- 기존 스킨·관절 길이·관절 스케일을 유지한다. FBX 단위/축 커브로 인한 스킨 왜곡을 피하도록 검증된 60 FPS 포즈 데이터를 재생한다.
