# 권민준 모션 적용 목록

사용자가 제공한 6 ZIP 중 하나는 빈 ZIP이며, 나머지에는 총 20개의 FBX 후보가 있습니다. 후보마다 동일한 Mixamo 리그와 메시가 포함되어 있습니다. 원본 파일에는 컬러 텍스처가 없고 기존 캐릭터와 UV가 달라, 새 메시를 기존 텍스처로 덮어씌우지 않았습니다. 기존 권민준의 메시·UV·텍스처·크기를 유지하고 실제 애니메이션을 기존 휴머노이드 관절로 베이크했습니다. 모든 원본은 작업 공간에 보관하며 게임은 기존에 검증된 PlayerModel 프리팹을 그대로 사용하고, 20개 후보의 60 FPS 베이크 포즈 데이터를 별도로 재생합니다. 새 FBX 프리팹을 게임 캐릭터로 교체하지 않았습니다.

## 동기화와 검사

- 시각 코드 `AuthoredPlayerView`를 전투/이동 코드와 분리. 기존 HP, 공격력, 판정 위치, 준비/회복 시간, 무적, 맵 충돌체를 수정하지 않음.
- 실제 타격 이벤트가 발생한 프레임에 타격 포즈를 맞추고, 그 이벤트부터 기존 회복 시간에 맞춰 회복 구간 재생. 동작 간 90 ms 포즈 블렌드.
- FBX는 정적 스킨만 사용. Unity Legacy 애니메이션의 단위/스케일 커브 문제를 피하도록 Blender에서 검증한 모델 공간 회전 델타와 힙 변위를 별도 데이터로 재생. 관절 길이와 스케일은 변경하지 않음.
- FBX의 평면 루트 이동 제거. 점프의 시각 높이를 물리 높이와 중복 적용하지 않음.
- 기존 모델은 렌더링하지 않는 보완 포즈 드라이버로 남음. 미제공 동작만 이 경로를 사용.
- 공격 중 축 발의 평면 위치 고정. 앉기 유지 중에도 공격·피격·사망·공중 동작 우선순위를 보존.
- 후보 20개 전부를 Unity에서 각 11개 구간으로 샘플링해 스킨 폭발, 비정상 좌표, 물리 루트/충돌체 변경 여부 확인.
- 최종 재검수 1: 1280×720 / 60 FPS 목표. 최종 재검수 2: 1024×768 / 30 FPS 목표. 브라우저 성능은 실제 기기/실행 환경에 따라 달라짐.
- 공격·강공격·방어 충격·피격에 의한 공격 취소·앉기·회피·잡기·궁극기 1/2/3·일시정지·사망·재시도 경로 검사. 기존 HUD/덩치/튜토리얼/고정 카메라 검사도 유지.
- 결과는 같은 소스 커밋의 `verification/summary.json`과 실제 브라우저 캡처로 기록. 실패 시 배포 차단.

현재 전투 코드에는 별도 바닥 다운/기상 상태가 없어 Sitting/Sit To Stand를 전투 피격에 연결하지 않았습니다. 손가락 리그/전용 주먹 스킨은 기존 캐릭터에 없으므로 새 모션의 손가락 움직임은 전달되지 않습니다. 자료가 없는 기술을 Mixamo 원본이라고 표시하지 않습니다.

## 2026-10-14 임의 모션 제거

사용자 요청에 따라 플레이어의 절차식 모션 복사 경로를 삭제했다. 제공되지 않은 앉기·회피·잡기·3타 뒤후리기는 제공된 FightingIdle을 유지하며 전투 판정은 유지한다. 기존 플레이어·덩치·임시 NPC의 절차식 런타임 애니메이션을 중지했고, 도입부 전체 몸체를 65도 기울이던 가짜 수면 연출도 제거했다. 덩치 전용 제공 모션이 연결되기 전에는 정적 모델로 표시한다. 이전 절차식 코드의 직접 미리보기는 회귀 테스트에서만 사용되며 실제 게임에서는 실행되지 않는다.
