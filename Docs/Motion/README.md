# 모션 수정·검증 기록

선택 기본값: 1번. 팔다리를 따로 생성하지 않고 제공된 전체 모델을 유지한다. 주인공은 무릎을 접었다 펴는 앞차기, 덩치는 팔꿈치를 접었다 펴는 펀치로 기존 판정 시간에 연결한다. 기존 공격력, 이동 속도, 공격 판정, 맵은 유지한다. 앉기 키는 C를 유지한다.

첫 방식: 신체 영역별 가중치 재분배. 실제 자세 렌더에서 팔의 경계가 찢어지고 메시 변형이 최대 60배 발생하여 폐기했다.

자동 대안: 18mm 복셀로 만든 폐쇄형 임시 메시에서 Blender bone heat 가중치를 계산하고 원본 UV 메시로 부드럽게 전달했다. 원본 텍스처와 외형은 유지하고 임시 메시는 내보내지 않는다. 19개 뼈, 최대 4개 가중치를 사용한다. 무릎·팔꿈치·발목·몸통을 별도로 구동하고, 앉을 때 메시를 축소하지 않는다. 2관절 다리 IK로 발 접지를 유지한다. 공격은 준비→관절 접기→타격→회수 순서이며 StrikeStarted 이벤트가 타격 시점을 결정한다. 모델의 루트 이동은 기존 게임 물리가 담당한다.

설명해: 오프닝 종료부터 무한 체력. 덩치: 기본공격 과제부터 마지막 궁극기 과제 완료 전까지 무한 체력. 무한 체력도 피격/가드/패링/콤보/궁극기 적중 이벤트는 발생한다. 오프닝 명치만과 튜토리얼 완료 이후 실전 적은 유한 체력이다. HUD는 보호 상태에서 ∞ / ∞를 표시한다.

검증 자료: `skin-audit.json`은 Blender 메시의 실제 변형과 바닥 높이를 기록한다. Player/Deongchi 자세 PNG는 Blender 검증 렌더이며 인게임 사진이 아니다. 실제 웹 실행 사진은 배포 사이트 `/verification/motion-walk.png`, `/verification/motion-crouch.png`, `/verification/motion-kick.png`, `/verification/production-hud.png`에 게시한다. Unity 테스트 장면은 출시 장면과 분리한다.

## 재현

Blender 4.3.2에서 `SourceArt/Characters/Player.blend`, `Deongchi.blend`를 열면 리그·UV·텍스처가 포함된 편집 가능한 모델을 볼 수 있다.

```sh
blender -b -t 2 -P Tools/Motion/verify_poses.py
blender -b -t 2 -P Tools/Motion/rebuild_rigs.py
```

첫 명령은 자세 렌더와 변형 검증, 둘째 명령은 가중치를 재계산하고 Unity Resources의 FBX와 텍스처를 생성한다. Blender 원본은 Assets 바깥에 두어 Unity/CI가 Blender 설치 없이 FBX로 빌드하도록 했다.

자가 진단 중 실제 공격 테스트가 뒤따르는 HUD 테스트의 체력을 감소시키는 테스트 격리 문제를 발견하여, 두 테스트 사이에 체력을 복원하도록 수정했다. 검증 사진과 실제 검사 수/소스 커밋은 verification 브랜치에도 보관한다.

앉기 추가 점검: 얕은 무릎 굽힘에서 골반을 44cm 내리는 앉기 자세로 수정했다. 접지 다리는 IK 결과를 직접 적용해 골반 하강보다 관절 보간이 늦어지는 발 꺼짐을 방지하며, 공격하는 다리는 별도로 부드럽게 보간한다.

이동 추가 점검: 다리를 시간에 맞춰 흔드는 방식 대신 이동 속도에 보폭과 주기를 연결했다. 접지 발은 몸의 진행 반대 방향으로 이동시키고, 반대 발은 들어 올려 회수한다. 넓은 보폭에서 다리가 늘어나지 않도록 골반 높이도 다리의 도달 거리에 맞춰 조절한다.

웹 실행 첫 검사에서 FBX 계층의 비단위 스케일 때문에 BakeMesh 결과에 TransformPoint를 적용한 좌표 검사가 실패했다. 범위 제한을 완화하지 않고, 렌더러의 bone world matrix × bind pose × vertex 가중치 합으로 실제 스킨 정점의 월드 좌표를 계산하도록 검증 방법을 수정했다.

두 번째 웹 검사에서 공유 메시의 Read/Write 기본 설정이 꺼져 있어 CPU 정점 접근이 실패함을 확인했다. Characters 경로 전용 AssetPostprocessor와 빌드 전 설정 점검으로 Read/Write를 자동 활성화하고 뼈 계층 최적화는 비활성화한다. 실제 타격 이벤트와 관절 변화, 무한 체력 대상의 콤보 적중까지 검증을 보강했다.

실제 연속 공격 점검에서 준비 단계와 타격 단계가 서로 다른 다리를 선택하던 연결 문제를 발견했다. 게임 판정 시간은 유지하고 준비 이벤트를 각 공격 회차에 전달하며, 다음 타격 번호로 준비·타격 다리를 동일하게 선택하도록 수정했다. 타격 테스트의 초기 겹침 배치는 1.1m 전투 거리로 바꿔 실제 플레이 조건과 맞췄다. 브라우저에서도 기본공격 3회 과제 완료까지 확인한다.

타격·무한 HP·콤보 검사는 실제 웹에서 통과했다. 짧은 펀치의 특정 프레임 한 번만 검사하던 방식은 공격 구간 전체를 관찰하여 팔꿈치가 준비 자세에서 실제로 펴지는 최대 각도를 측정하도록 변경했다. Rigidbody 위치만 변경한 뒤 SyncTransforms가 이전 Transform 위치로 되돌리는 테스트 배치 문제도 Transform과 Rigidbody 위치를 함께 지정하여 수정했다.

와이드 해상도 검사에서 느린 렌더 프레임 때문에 0.1초짜리 공격 판정이 첫 FixedUpdate 전에 만료되는 간헐적 누락을 발견했다. 공격 생성 시에도 기존과 동일한 OverlapBox와 적중 중복 방지를 사용해 즉시 검사하도록 수정했다. 공격력·범위·유효 시간은 변경하지 않았다.

다음 실행에서는 해상도 4종 × 120항목이 모두 통과했다. 실제 교실 장면의 자동 조작은 소프트웨어 WebGL 스크린샷 촬영 동안 이동 키를 계속 유지하여 상대를 지나친 뒤 허공에 공격하는 문제를 보였다. 검증 URL에서만 활성화되는 읽기 전용 위치 관측으로 실제 키 입력을 조절하고, 촬영 지연 후 새 연속 공격을 입력하도록 수정했다. 관측 기능은 캐릭터 위치·체력·전투 상태를 변경하지 않는다.
