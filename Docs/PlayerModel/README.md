# Tripo 주인공 모델 적용

사용자 제공 `businessman suit 3d model.zip`의 GLB를 주인공 외형으로 사용합니다.
원본: 약 196만 삼각형, 텍스처 3개, 뼈대/애니메이션 없음.
Blender에서 약 2만 삼각형/16,471 정점으로 단순화하고 1.85m로 정규화했습니다.
베이스 컬러 1024px를 사용하고 FBX를 Unity Resources에 포함합니다.

19개 뼈대를 새로 구성하여 자동 가중치 뒤 누락 정점 1,392개를 가까운 가중치 정점 기준으로
보정했습니다. 모든 정점은 최대 4개 영향과 합계 1의 가중치를 갖습니다.
ImportedPlayerView는 기존 CombatActor/PlayerController 상태를 읽어 기본 보행/킥/가드/
앉기/사망 자세 및 튜토리얼의 강제 킥을 표시합니다. 이것은 새로 만든 간단한 절차적 포즈이며
원본에 전용 애니메이션이 있었다는 의미가 아닙니다. 정교한 팔꿈치/무릎 및 잡기 모션은
후속 애니메이션 작업 대상입니다. 적, 전투 판정, HP, 조작키, 맵은 변경하지 않습니다.

실제 Unity 테스트에서 리그, 정점 수, 텍스처, 크기, 강제 킥과 스킨 변형을 검사하고
기존 HUD 검사와 함께 4개 해상도에서 실행합니다. 배포 씬에서는 모델 로드 로그와
이동/앉기/점프/공격 입력을 확인합니다. 성공한 실제 인게임 캡처는 기존 웹 주소의
verification/production-hud.png에 게시합니다. blender-preview.png는 Blender 렌더이며
실제 게임 화면과 구분합니다.
