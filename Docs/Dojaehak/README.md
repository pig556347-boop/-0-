# 도재학: 첫 중간보스

제공된 33개 분할 파일을 복원해 모델과 10개 모션을 확인했다. 원본 스킨의 24,996개 정점·50,000개 삼각형, 65개 뼈와 52개 가중치 그룹을 사용한다. UV와 상위 네 가중치를 보존하고 기본 색상을 2K로 정리했다. 기본 FBX는 정적 메시지만 모션 FBX에는 일치하는 스킨·뼈대가 있어 추가 리깅 없이 사용했다. 걷기·Run Forward와 여덟 공격을 각각 보관한다. 이번 파일은 Punching이 왼손(63프레임), Punching (1)이 오른손(52프레임)이어서 실제 손에 맞춰 연결했다.

## 패턴

| 상황·패턴 | 사용 동작 | 대응·빈틈 |
| --- | --- | --- |
| 근접 원투 연계 | 왼손→오른손→MMA 킥 | 각 타격 전 전조, 뒤로 빠지면 후속타 취소 |
| 중거리 견제 | 옆차기→훅 | 옆으로 회피하거나 접근해 강공격으로 끊기 |
| 거리 좁히기 | 예고→실제 달리기→돌려차기 | 돌진 자체에는 피해 없음, 돌려차기는 방향 고정·회피 후 반격 |
| 가드 압박 | 훅→4연타 | 전조 후 네 판정, 모두 가드 가능·연타 뒤 0.9초 회수 |
| 발차기 변형 | Kicking→돌려차기 | 준비·회수 간격이 달라 타이밍 변주, 거리 벌리면 중단 |

거리·가드 상태·선호 확률·기술별 쿨다운·직전 패턴을 함께 고려한다. 정해진 순서를 강제 반복하지 않는다. 체력 50% 이하에서는 가드 압박 선호와 패턴 사이 압박 빈도가 높아지고, 피해량 자체를 갑자기 올리지는 않는다. 전환에도 짧은 전조를 둔다.

공격 중에는 방향이 고정되어 회피한 플레이어를 즉시 따라 돌지 않는다. 연계 사이에는 거리를 다시 확인해서 범위 밖 후속타는 취소한다. 큰 기술의 예고 후반·공격 순간만 약한 타격에 대한 경직 저항을 주며, 피해는 그대로 받는다. 강공격·일반 발차기 마지막 타·궁극기·타이밍 방어는 이를 끊을 수 있다. 회수 구간에는 저항이 없다. 연계가 두 번 끊기면 다음 옆차기에는 “버티고” 전조와 함께 준비 초반에도 경직 저항을 한 번 적용해 약한 공격만으로 무한히 멈추는 것을 방지한다. 이 경우에도 강공격·궁극기·타이밍 방어·가드·회피 대응은 유지된다. 고유 패턴 종료 후에는 추가로 1.25초(후반 0.9초)의 판단 휴지가 있으며 기술별 재사용 간격도 둔다. 순간이동·무적 돌진·가드 불가능한 필수 피해는 넣지 않았다.

## 모션과 판정

원본 Quad Punch의 30·42·56·70 프레임에 대응하는 네 판정을 각각 한 번만 생성한다. 게임상의 타격 간격은 0.30·0.30·0.34초로, 일반 피격 경직 0.25초보다 길다. 가드를 유지해 후속타를 방어하거나 첫 전조를 보고 회피할 수 있다. 각 구간 사이를 실제 모션 접촉 프레임에 맞춰 보간해 팔이 뻗을 때 피해가 나도록 한다. 훅은 준비·정리 부분을 줄여 35~95프레임의 공격 구간을 사용한다. 원본 전체 클립은 보존한다.

공격 루틴은 CombatActor 소유여서 경직·사망·복구·비활성화 시 기존 취소 경로에서 지연 판정도 제거된다. 보스 AI는 대상 사망·입력 비활성화·EnemyBrain.Active=false에도 연계를 취소한다. 기존 잔몹 및 다른 보스의 기본 AI·공격 시간과 플레이어 조작·카메라는 유지한다. 도재학만 1-5 간부전에서 새 컨트롤러와 모델로 생성한다.

Blender에서 10개 모션을 11개·21개 구간으로 두 번 검사한 기록은 `offline-audit.json`, 원본 접촉 구간은 `import.json`이다. `source-*.png`는 사전 검사 이미지다. Unity에서는 스킨·동작뿐 아니라 실제 피해, 4연타의 중복 방지, 가드·회피·패링·강공격·궁극기 중단, 회피 후 추적 방지, 거리 이탈·일시정지·사망 취소, 다섯 연계와 자율 추격을 검사한다. 최종 실행 결과는 아래에 기록했다.
