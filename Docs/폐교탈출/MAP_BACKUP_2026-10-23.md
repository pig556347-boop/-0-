# 폐교탈출 맵/방 구조 백업 — 2026-10-23

> 목적: Codex가 이후 구현 작업에서 현재까지의 공간 설계 결정을 잃지 않도록 보존하는 기준 문서.
> 이 문서는 **현재 대화 기준 최신안**을 우선한다. 과거 이미지 시안 중 사용자가 수정/폐기한 내용은 확정안으로 보지 않는다.

---

## 0. 공통 원칙

### 게임 시점 / 분위기
- 탑다운/2.5D 폐교 액션 호러.
- 아오오니처럼 캐릭터가 맵을 직접 이동하는 구조.
- 어둡고 낡은 학교, 좁은 조명, 긴 복도, 코너, 막다른 길, 숨을 수 있는 가구를 적극 사용.
- 방과 방을 너무 촘촘히 붙이지 않는다. **방 사이에 복도, 코너, 우회 동선, 막다른 길을 넣어 찾는 재미**를 만든다.
- 플레이어가 추적자에게 쫓길 때 직선으로만 달리지 않도록 캐비닛/책상/교탁/침대/사물함 등 숨기 요소를 배치한다.

### 랜덤화 원칙
초기 구현 단계:
- 층별 기본 맵 프리셋은 고정.
- 2층은 **프리셋 1번을 기본 개발 맵**으로 사용.

안정화 이후:
- 맵 프리셋 자체가 판마다 랜덤.
- 열쇠 3개 위치 랜덤.
- 친구 위치 랜덤.
- 잠긴 방/구역 랜덤.
- 필요한 도구 및 일부 아이템 위치 랜덤.
- 일부 괴이/몹/숨기 포인트도 랜덤 가능.

# 1. 본관 1층 — 현재 기본안

## 핵심 구조
- 1층은 행정/공용 시설 중심.
- 방들이 서로 붙지 않게 배치하고 복도와 코너를 충분히 둔다.
- 2층 이동 계단은 **도서실과 교직원 화장실 사이의 계단 1곳**을 기준으로 한다.
- 과거 동쪽/서쪽 계단 시안은 삭제.
- 복도 끝 막다른 구역에 학생용 화장실을 배치할 수 있다.
- 빈교실을 추가해 탐색 공간과 사각지대를 늘린다.

## 주요 공간
- 현관/중앙홀
- 방송실
- 학생용 남자 화장실
- 학생용 여자 화장실
- 교직원 남자 화장실
- 교직원 여자 화장실
- 도서실
- 행정실
- 세미나실
- 양호실
- 대회의실
- 창고
- 설비관리실
- 빈교실 1~2개 이상
- 2층으로 올라가는 계단

## 화장실 공통 원칙
- 학생용 남/여, 교직원 남/여는 구조를 거의 동일하게 만들어 재사용 가능.
- 성별/교직원용 여부에 따라 소품과 접근 조건만 변형.

# 2. 본관 2층 — 맵 프리셋 시스템

## 현재 개발 우선순위
- **프리셋 1번 = 초기 제작 기준 맵**
- **프리셋 2번 = 예비 변형 맵**
- 이후 게임 안정화 후 판마다 1/2 등 여러 프리셋 중 랜덤 선택.

## 공통 구조
- 중앙은 1층이 보이는 오픈홀 금지.
- 중앙 공간은 **벽으로 막혀 시야가 통하지 않음**.
- 전체는 `-0-` / 역U형 순환 복도 느낌.
- 반/특별실을 일정 거리 이상 띄워 배치.
- 긴 복도, 꺾이는 복도, 사각지대, 빈교실을 넣어 약간 미로처럼 구성.
- 상단에는 **3층으로 가는 계단**.
- 서쪽 끝: **서관 연결 통로**.
- 동쪽 끝: **별관 연결 통로**.
- 1층/3층에는 본관↔별관 실내 연결부 없음. 실내 연결은 2층 전용.

## 주요 공간
- 2학년 1반
- 2학년 2반
- 2학년 3반
- 2학년 4반
- 2학년 교무실
- 음악실
- 미술실
- 컴퓨터실
- 도서실
- 준비실
- 자료실
- 창고
- 학생용 남자 화장실
- 학생용 여자 화장실
- 교직원 남자 화장실
- 교직원 여자 화장실
- 빈교실 여러 개
- 서관 연결 통로
- 별관 연결 통로
- 3층 계단

## 배치 원칙
- 2학년 1~4반을 한 줄로 따닥따닥 붙이지 않는다.
- 음악실/미술실/컴퓨터실/도서실도 서로 분리해 목적지를 찾는 동선을 만든다.
- 반과 반 사이에 복도/코너/빈교실/서비스 공간을 끼운다.

# 5. 방송실 — 기능 확정 / 내부 배치는 재작업 필요

> 이전 방송실 이미지 시안은 사용자가 "학교 방송실답지 않다"고 판단해 **확정안 아님**.
> Codex는 이전 이미지 레이아웃을 그대로 구현하지 말 것.

## 크기
- 일반교실보다 작게.
- 교실 V1 면적의 약 60~70% 체감.
- 좁고 장비가 많아 답답한 느낌.

## 역할
- 퍼즐방보다 **아이템 탐색/드랍 중심 방**.
- 여러 수납부를 조사하며 자원/열쇠/힌트를 얻는다.

## 조사 포인트 후보
- 방송 메인 콘솔 서랍
- 믹서/음향장비 아래 수납장
- 장비 랙
- 방송부 책상 서랍
- 서류 캐비닛
- 녹음테이프/CD 보관함
- 마이크/촬영장비 보관함
- 벽걸이 방송 TV 아래 수납부
- 쓰레기통/바닥 가방
- 잠긴 개인 사물함

## 드랍 후보
- 건전지
- 소형 열쇠
- 메모
- 카세트/녹음 자료
- 퓨즈
- 전선/절연테이프
- 소형 공구
- 학생증
- 간식/회복 아이템
- 교내 지도 조각
- 비밀번호 힌트
- 교직원증(희귀)
- 휴대용 무전기(희귀 아이템 후보)

## 드랍 규칙 제안
- 조사 포인트 약 10~15개.
- 실제 아이템 생성은 4~7곳 랜덤.
- 메인 콘솔/서류 캐비닛/잠긴 사물함은 상대적으로 가치 높은 보상 후보.

# 6. 음악실 — 현재 V3 기준

## 크기/분위기
- 일반교실보다 넓게.
- 학교 특별실 중 공포 분위기를 강하게 담당.
- 낡은 학교 음악실 느낌. 현대식 스튜디오처럼 세련되게 만들지 않는다.

## 구성
### A. 메인 음악실
- 넓은 합주 공간.
- 피아노/그랜드피아노.
- 여러 음악 책상/의자.
- 화이트보드 또는 음악 수업용 보드.
- 교구/악보 캐비닛.
- 벽 사이사이에 **유명 음악가/작곡가 초상화 여러 장** 배치.
- 초상화는 추후 괴이/힌트/맥거핀 연출에 활용 가능.

### B. 악기보관창고
- 단순 악기 진열장이 아니라 **창고 느낌**.
- 악기 케이스, 비품, 박스, 선반, 낡은 악기, 청소도구가 섞임.
- 아이템 드랍 주요 장소.
- 조사 가능한 선반/박스/케이스 다수.

### C. 보컬룸
- 기존의 세련된 녹음실 스타일 금지.
- **학교 음악실에 딸린 낡은 소형 보컬 연습실** 느낌.
- 저가형 흡음재, 오래된 마이크, 마이크 스탠드, 작은 책상/의자, 낡은 스피커/앰프, 악보 받침대 등.
- 메인 음악실과 톤앤매너 통일.

### D. 연결 통로
- **메인 음악실 ↔ 보컬룸 사이에 작은 통로**.
- 통로 중간/측면에 문을 두어 **악기보관창고로도 이어짐**.
- 통로는 음악실과 같은 낡은 벽/바닥/조명 재질 사용.
- 별도 현대식 복도처럼 보이지 않게 한다.

## 공포 연출 후보
- 피아노 자동 연주
- 초상화 시선 변화
- 악기보관창고 안 소리
- 악보가 바닥에 흩어진 상태
- 일부 책상/악기 파손
- 혈흔은 과도하게 고정하지 않고 맵 변형 요소로 활용 가능

# 7. 미술실 — 현재 기본안

## 크기
- 일반교실보다 크게.
- 작업 테이블과 이젤이 여러 개 들어갈 수 있는 넓은 특별실.

## 메인 미술실 구성
- 긴 실생/작업 책상 여러 개.
- 이젤 다수.
- 교탁/교사 작업대.
- 세면대/물 사용 구역.
- 캔버스/작품/미술 도구.
- 방 중앙 및 주변에 **하얀 석고상/조형물** 여러 개.
  - 석고 흉상
  - 전신/반신 조각
  - 손/발 모형 등
- 조형물은 미술실 공포 분위기의 핵심 시각 요소.

## 미술실 창고
- **일반교실 약 1/2 크기**.
- 메인 미술실과 붙어 있는 별도 공간.
- 캔버스
- 이젤
- 석고상
- 물감/도구/재료
- 작품 보관
- 박스/선반
- 조사 가능한 저장 공간 다수.

## 조사 포인트
- 석고상/조형물
- 작업 책상 서랍/아래
- 세면대 주변
- 이젤/캔버스
- 교탁
- 창고 선반/박스/도구함

# 8. 도서실 — 현재 초안 (후속 수정 가능)

> 사용자가 "기존 맵 중 가장 크게" 요청한 상태.
> 아직 최종 수정 피드백 전이므로 **현재는 초안**.

## 크기
- 본관 실내 공간 중 최상위급 크기.
- 일반교실 여러 개를 합친 규모.

## 현재 구역 아이디어
- 출입구
- 자료검색대/대출 데스크
- 사서실
- 대형 서가 구역
- 일반 열람 테이블
- 개인 열람석
- 도서 보관창고
- 중앙 오브젝트/조형물
- 깊은 서가 사이 좁은 통로

## 플레이 목표
- 넓은 서가 때문에 시야가 끊김.
- 추적자와 숨바꼭질에 유리/불리한 구간이 동시에 존재.
- 책장 사이를 돌아다니며 아이템/힌트를 찾는 탐색 방.

## 조사 포인트
- 대출/검색 데스크
- 서가
- 책상/열람석
- 사서실 책상/서랍
- 도서 보관창고
- 특정 책/책장
- 중앙 조형물

# 10. Codex 구현 시 주의

1. 이 문서는 **맵/방 구조의 설계 기준**이며 아직 즉시 구현 명령이 아니다.
2. 사용자가 "한꺼번에 코딩 명령을 내리겠다"고 했으므로, 구현 시작 전 별도 지시를 기다린다.
3. 교실 V1은 일반 교실의 공통 프리팹 기준으로 사용할 수 있게 설계한다.
4. 방별 오브젝트는 최대한 상호작용 가능한 개별 엔티티로 설계 가능하도록 준비한다.
5. 맵 구조 랜덤화는 초기 버전에 바로 넣지 않는다.
6. 우선 프리셋 고정 상태에서 게임 플레이가 안정화된 뒤 맵 프리셋 랜덤화를 추가한다.
7. **방송실은 내부 구조 재설계가 필요하므로 이전 이미지 시안을 구현하지 않는다.**
8. 음악실/미술실/도서실은 특별실별 톤과 기능을 분명히 구분한다.
9. 이미지 시안보다 사용자의 후속 텍스트 수정 지시가 항상 우선한다.
