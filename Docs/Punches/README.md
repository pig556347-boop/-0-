# 펀치 공격과 일시정지 음악

- I: 펀치. 각 캐릭터의 첫 공격은 왼손, 두 번째는 오른손, 세 번째부터 좌우 무작위. 마지막 펀치로부터 3초가 지나면 새 순서를 시작한다. I 연속 입력은 공격 중에도 예약할 수 있다.
- J/K: 기존 플레이어의 일반 발차기/강공격. L: 기존 가드 및 타이밍 방어. I 잡기 과제는 I 펀치 적중 과제로 교체했다.
- 적의 기본/강공격은 동일한 펀치 선택 규칙을 사용한다. 플레이어와 덩치는 첨부 FBX를 기존 스킨에 리타기팅하며, 뼈대가 없는 일반 적 임시 모델은 좌우 팔 피벗으로 선택된 펀치를 표시한다. 보스 궁극기는 별도 동작으로 유지된다.
- 첨부 `Inward Block`은 플레이어의 방어 피격 및 덩치의 가드 표시에 사용한다.
- Esc 일시정지는 음악 재생 위치를 저장하고 멈춘다. 재개하면 해당 위치부터 이어진다. 피격의 짧은 히트스톱에는 음악을 멈추지 않는다.

제공한 세 파일은 60 FPS, 왼손 63프레임·오른손 60프레임·막기 88프레임으로 변환했다. 손의 전방 도달 거리에서 측정한 타격 시점은 각각 34/60초, 24/60초다. 실제 대미지 시점은 기존 전투 시계를 사용하며, 시각 모션을 그 시점에 맞춘다. 수평 루트 이동은 제거했고 기존 메시와 텍스처를 유지한다.

검증 기록은 동봉 JSON과 WebGL CI 실행에 대응한다. 펀치 전용 테스트는 별도 테스트 장면에서 수행하고, 기존 덩치전 테스트는 튜토리얼 신호를 가속한 후 실제 AI·피해·재시도·캠페인 전환을 검사한다. 전체 캠페인을 수동으로 완주했다는 의미는 아니다.
