# KICK Back 로비·튜토리얼

실행 소스: `69b812c15b8baac6fd9b7745a2ea0db32c26cf38`.

## 로비

- 게임이 자동으로 시작되지 않는다. 게임시작을 선택한 뒤에만 기존 인트로와 튜토리얼이 생성된다.
- 메뉴: 게임시작 / 언어 / 설정 / 제작자. 석양 교실 배경은 이번 작업에서 제작한 AI 일러스트다. 제목은 실제 UI 텍스트로 표시한다.
- 한국어·영어 메뉴와 핵심 조작 안내. 기본 언어는 한국어이며 선택을 저장한다.
- 전체·음악·효과음 음량과 전체화면 전환. 음량은 저장하며 실제 AudioListener 및 음악·효과음 채널에 적용한다.
- 제작자 표기는 현재 GitHub 계정 pig556347-boop를 사용한다.
- Esc로 일시정지한 뒤 로비로 돌아갈 수 있다.

## 튜토리얼

기존 짧은 상단 문구와 별도로 큰 설명 카드, 현재 허용 키, 잘못된 키 안내, 단계 완료 피드백을 표시한다. 필요하지 않은 이동·전투 입력을 양쪽 입력 경로에서 차단한다. Esc 일시정지는 항상 사용할 수 있다.

| 단계 | 허용 조작 | 성공 조건 |
|---|---|---|
| 이동 | WASD | 바닥에서 2m 이동 |
| 점프 | Space | 점프 후 착지 |
| 앉기 | C | 0.6초 유지 |
| 기본공격 | WASD, J | 가까이에서 3연타 연속 적중 |
| 강공격 | WASD, K | 강공격 적중 |
| 막기 | L | 정면 공격 방어 |
| 패링 | L | 공격 직전에 타이밍 방어. 공격 예고와 누를 타이밍 안내 |
| 회피 | Shift + WASD | 방향 회피 실행 |
| 잡기 | WASD, I | 가까이에서 잡기 성공 |
| 게이지 | WASD, J, K | 구슬 3개 충전 |
| 궁극기 | WASD, Q | 3단 궁극기 적중. 빗나가면 종료 후 게이지를 재충전해 재시도 |
| 완료 | 기존 모든 조작 | 자유 연습 및 이후 전투 |

## 음향

타격 이펙트·타격음·로비 음악·전투 음악은 추가 가능하다. 이번에는 새 음원 파일을 넣지 않았다. 선택적으로 다음 리소스를 추가하면 준비된 채널이 사용한다.

- `Assets/Resources/Audio/LobbyMusic.ogg`
- `Assets/Resources/Audio/BattleMusic.ogg`
- `Assets/Resources/Audio/Hit.wav`

기존 타격 피드백은 유지한다. 공격키 개편·J 2타 변경·시체 떠오름 수정은 이번 로비·튜토리얼 작업 범위에 포함하지 않았다.

## 실행 검수

실제 WebGL에서 네 메뉴 클릭, 네 해상도, 언어 변경, 음량 변경과 새로고침 후 저장, 게임시작 전 전투 미생성, 시작 후 인트로, 일시정지 후 로비 복귀를 검증한다. 점프 단계의 이동·공격·앉기 차단, 점프 후 착지, 앉기 유지, 기본공격 3타, 강공격 후 다음 단계 진행을 실제 키 입력으로 검증한다. 기존 모션 검수 두 차례와 HUD·고정 카메라·교실 검사도 유지한다. 결과는 verification.json과 lobby-tutorial.json에 기록한다.
