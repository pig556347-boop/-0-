# 잔몹4 통합

잔몹3 단계의 실제 Unity 검증을 완료한 뒤 진행했다. 제공된 15개 볼륨에서 기본 FBX와 걷기·펀치 2종·MMA 킥을 모두 복원했다. 기본 FBX는 정적 메시지만 모션 파일에는 원본 스킨과 같은 33개 뼈·28개 가중치 그룹이 들어 있어 제공 가중치를 보존했다. 원본 정점 25,000개·삼각형 49,999개·UV를 유지하고 기본 색상은 게임용 2K로 정리했다.

서로 다른 좌우 펀치를 그대로 사용한다. 타격 시 팔꿈치는 오른손 180도·왼손 약 142도다. 전용 Walking과 제공된 121프레임 MMA 킥을 사용하며 킥 타격 기준은 38번 프레임으로 맞춘다. 이는 기존 게임 타격 시각에 맞춰 동작을 정렬하기 위한 기준이며, 공격 간격·준비·회수 시간은 변경하지 않는다. 준비·피격·방어는 기존 제공 모션을 연결했다.

잔몹1~4를 스테이지·라운드마다 순환 배치한다. 초반 세 명 제한에서도 1-2부터 잔몹4가 등장하며, 네 명이 나오는 1-6에서는 네 종류의 동시 생성을 검사한다. 체력·피해·AI 공격 간격·이동 속도·카메라 확대는 기존 설정을 유지했다.

Blender에서 네 모션을 11개·21개 구간으로 두 차례 재검토했다. `offline-audit.json`은 실제 변형 메시와 팔꿈치 수치, `source-*.png`는 사전 검사 이미지다. Unity에서는 네 모델별 모션·스킨·AI 타격·피격·사망·복구, 혼합 생성과 후기 시체 정리 및 기존 전체 회귀 검사를 실행한다. 실제 결과는 완료 후 기록한다.
