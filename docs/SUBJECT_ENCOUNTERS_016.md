# 0.16 · 음악실 / 과학실 / 도서실

2026-10-28. 기존 0.15에서 이어 구현했다. 다른 게임 코드·에셋은 사용하지 않았다. 기능은 현재 독립 브라우저판에 구현되어 있다. Unity 네이티브 게임플레이 이식은 아직 필요하다.

## 플레이 흐름

- 도서실 대출·반납 기록대를 E로 조사 → 기록 읽기 → 기록 순서에 맞는 분류 서가를 찾아 E로 조사 → 맞는 책 버튼 선택. 세 권을 마치면 안쪽 보관함에서 손전등·비타민워터를 직접 클릭하여 가져온다. 틀린 선택은 진행을 초기화하고 주변 당직자가 들을 수 있는 소음을 낸다.
- 실험복은 본관 3층 과학 자료실 캐비넷. 기존 카드키/자료실 잠금은 유지한다. 손전등 옆 메모와 별도 가이드북에 다음 단서가 있다.
- 과학실은 실험복·손전등 모두 소지한 상태에서 앞문 E로 입장. 미로 끝 뒷문 옆 캐비넷의 **밀봉된 실험 표본**을 클릭해서 얻으면 뒷문이 열린다. 표본을 얻기 전 앞문으로 철수할 수 있다. 복도 쪽 뒷문은 잠겨 있어 역진입으로 생략할 수 없다.
- 음악실은 입장하면 새로 만든 피아노 선율이 68→220 BPM으로 약 32초 동안 빨라진다. 불협화음 한 번 후 약 1초 뒤 거대한 머리의 음악가가 나타난다. 음악실·보컬룸·악기창고 연결 공간 안에서 벽과 가구를 피해 추적한다. 밖으로 나가면 추격이 끝나고 재입장 시 다시 시작한다.

## 해석과 기본 선택

1. “10초에 한 번 2초간 점등(시야 완전 차단)”은 문맥에 따라 **소등**으로 해석했다. 입장 후 10–12초, 20–22초, 30–32초… 모든 월드 시야와 미니맵이 차단된다. 플레이어는 계속 이동할 수 있다. 일시정지/조사 중에도 어두운 월드를 노출하지 않는다.
2. 세 번째 소등 종료 시 발소리, 1.2초 후 쉐도어 정확히 두 마리. 다음 소등부터 움직인다. 점등 때는 완전히 정지하며 잡지 않는다. 소등 때 길찾기로 추적하고 접촉하면 기존 난이도별 포획 처리를 사용한다.
3. 실험복과 손전등은 각각 가방 한 칸, 소지 검사 방식. 스마트워치용 착용 한 칸과 가이드북 전용 영역은 그대로 둔다. 두 장비는 소등 때 시야를 되살리지 않는다.
4. 과학실 사망 시 노말/하드의 일반 아이템 드롭 규칙을 유지하되 **입장 장비 두 개만 앞문 바깥 복도로 옮겨 떨어뜨린다**. 장비 없이 안쪽 장비를 주워야 하는 막힘을 방지한다. 과학실 안에서는 두 입장 장비의 수동 버리기를 막고 안내한다. 이지는 기존대로 보존.
5. 과학실 재입장 시 소등 횟수·쉐도어 스폰을 초기화하므로 사망 후 다시 등장한다. 표본 획득에 따른 뒷문 개방은 같은 판 동안 유지한다.
6. 개발용 추적자 OFF는 새 몬스터도 정지·숨김 처리한다. 과학실 조명과 퍼즐은 계속 작동한다. ON으로 되돌리면 해당 장면 상태에 맞춰 재개한다.
7. 방 이벤트 중 당직자는 별도로 움직이지 않아 방 전용 괴물과 중첩 공격하지 않는다. 음악가/쉐도어는 해당 방에서만 등장한다.
8. 도서실은 분류번호 6종 중 매판 3종의 순서를 생성한다. 기록은 가이드북에 보존된다. 기존 음악실 크기/가구/보컬룸/창고 구조는 유지했다.
9. 과학실 보상 종류가 지정되지 않아 표본과 초코바를 선택했다. 표본은 회수 확인용이며 기존 A/B/C 교문 탈출 조건은 바꾸지 않는다. 발전기·다른 신규 몬스터는 이 변경에 포함하지 않는다.

## 저장 / 재개

`school.save016` / 버전 16을 사용한다. 기존 0.15 저장은 삭제하지 않지만 새 빌드에서는 새 판으로 시작한다. 도서 반납 진행·해결 여부, 표본 회수, 인벤토리, 기존 해제 상태를 저장한다. 활성 추격 중 저장은 막는다. 방 재입장/불러오기 때 연출 타이머와 괴물은 안전한 초기 상태로 시작한다.

구현: `Tools/subject_rooms.py`, `Web/subject-events.mjs`, `Web/subject-visual.mjs`, `Web/audio.mjs`. 공유 지도에 과학실 미로·앞뒷문과 도서실 서가를 반영한다. 빌드는 `node SchoolEscape/Tools/build_web.cjs <출력>/index.html`로 만든다.

## 추가 요청 · 로비와 클릭 입력

- 시작 로비에 게임 시작, 저장한 판 계속하기, 설정, 언어, 난이도 선택을 배치했다. 폐교 외형 배경은 새 CSS 도형으로 제작했다.
- 설정은 전체 음량/음소거. 게임 중 Esc → 설정에서도 같은 값을 사용하며 로컬 저장한다.
- 한국어/영어 **메뉴·설정** 지원. 방 이름, 문서, 단서와 나머지 게임 HUD의 완전한 영어 번역은 아직 하지 않았다. 언어 화면에 적용 범위를 표시한다.
- Esc → 로비로는 메모리의 현재 판을 유지한다. 게임 계속으로 복귀하거나 새 판 시작을 선택할 수 있다. 영구 저장은 기존 현재 판 저장 버튼이다.
- 조사/가방/잠금 창에서 E를 다시 누르면 닫는다. 반복 키다운은 무시하며 닫는 키가 바로 뒤의 문/조사를 다시 실행하지 않도록 이벤트 전파를 막는다.
- 방향 잠금은 십자 배열 화면 버튼, 숫자 4/6자리 잠금은 도어락 형태의 0–9, 한 칸 지우기, 전체 지우기, 잠금 해제 버튼을 사용한다. 물리 키보드로 답안을 직접 입력하지 않는다. 버튼의 Tab/Enter 접근성은 유지한다.
- 로비의 기존 게임 저장과 기본 난이도/소리 설정을 보존한다. 추가 외부 에셋은 없다.
- 검사: `Tools/lobby016_browser_check.mjs`에서 E 닫기·다시 열기, 4/6자리·방향 클릭 입력, 입력 불가/지우기, 설정·언어 재실행 유지, 로비 왕복/390px 화면을 실제 Chromium으로 확인한다.

최종 로컬 확인: 특별실 32개, 로비/키패드 30개, 기존 전체 회귀 77개 통과. 실행/콘솔 오류 0. 숨겨진 조사 창에 초점이 남는 문제를 고쳐 E 닫기 후 I 재열기를 검증했다. 공개 URL에서도 동일 파일을 다시 검사한다.
