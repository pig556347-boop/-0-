## 크기와 가구

- 일반 교실: 18×18 → 18×16 격자. 1격자 1.25m, 책상 30석의 기본 배치. 각 판 테마에 따라 일부 파손/빈 자리. 일반 학년 교실이 대부분 비어 보이는 테마는 제외하고 기존 무작위 위치 변경은 같은 층 안에서 유지.
- 교무실: 28×26 → 18×18 격자. 담임 6석 + 과목교사 4석. 담임 반/과목은 명패와 조사 제목에 표시.
- 1학년 과목교사: 기술·가정/국어/영어/체육. 2학년: 컴퓨터/수학/과학/음악. 3학년: 지리/사회/미술/진로.
- 큰 지원실: 가구 자체의 미터 치수·높이는 유지하고, 가구 조립체 간 간격과 방 외곽을 대체로 약 15% 축소. 출입과 조사 지점 검증 포함. 정확한 전후 치수는 `Evidence/expansion015-sizes.json`.
- 운동장·체육관·음악실 크기 보존. 음악실과 체육관의 격자·가구·동선 데이터 동일성 검사. 사용자가 지정한 조리실 한 칸 추격 동선, 작은 제어실, 화장실 칸막이, 연결 통로는 보존.
- 교실: 칠판·교탁·TV·시계·창문·개별 공책/필기구·청소함·서적함·뒤쪽 사물함 4개. 사물함은 각 4열×8행 개별 조사.
- 과학실: 실험대·싱크·수전·유리기구·실험 장비함·교탁. 기술가정실: 작업대·재봉틀·조리 실습대·도구함. 학생회실: 회의석·서류·문서함·게시판.

## 진행 규칙과 선택 기록

1. 질문 없이 요청대로 진행. 빈교실 수는 허용 범위 안의 2개를 선택해 일반/파손 교실 탐색을 보존.
2. 과학실에 준비실·약품 보관실을 함께 배치. 3층의 이전 미술실/컴퓨터실 자리는 학생 연구실·과학 자료실로 재활용.
3. 학년별 과목교사 4석은 지정 예시를 포함한 기본안. 특정 실습실과 교사의 소속 학년이 서로 달라도 요청한 예시 유지.
4. 층 카드키 순서 1→2→3→4→옥상. 서관/별관 카드키는 계속 2층에서 구함. 학생 교실 전용 열쇠와 교무실 반장 단서는 해당 층에 일치.
5. A/B/C 최종 탈출은 운동장 남쪽 교문 유지. 4층에도 소비 아이템을 배치. 기존 잠금/조리실 재도전/무제한 추격 스태미나 유지.
6. 저장 버전 15로 분리. 이전 `school.save014`는 삭제하지 않으나 확장판에서 불러오지 않음. 새 배치에서 새 판 시작 후 저장.
7. 방은 들어간 공간만 보이며 E로 출입, 계단은 자동 이동. 산책로/경비실도 개별 공간으로 전환.
