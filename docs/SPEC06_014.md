# 0.14 — 조리실 재도전과 시안서 v0.6 추가 기획 (2026-10-27)

사용자 요청 1~3과 첨부 v0.6을 비교했다. 문서 원문 추출/해시는 References/SPEC_V06_TEXT.txt, SPEC_V06_SOURCE.json에 저장했다. 문서의 기존 본편 MVP와 이번 추가 기획을 구분했다. 다른 게임 재사용, 4칸 가방, 친구/보스가 필요한 탈출 조건은 이전 사용자 확정안과 충돌하므로 적용하지 않았다. 가방9칸·별도 가이드북·착용1칸, A/B/C 운동장 교문 탈출을 유지한다.

## 조리실

- 수정 원인: 포획 후 `failed` 상태가 영구 유지되어 괴물 재시작 경로가 없었다.
- 처음 들어갈 때 괴물은 나타나지 않는다. 서쪽 길 끝 보급 상자(3,22)에 초코바와 배식 일지를 배치했다. E 조사→클릭 획득. 아이템 획득을 강제하지 않아 가방이 가득 차도 조사 진행은 가능하다.
- 상자를 조사한 뒤 북쪽 출입문으로 돌아오면 추격이 시작된다. 조사 전에는 북쪽 문을 통해 안전하게 되돌아갈 수 있다. 상자 앞에서 즉시 추격하지 않는다.
- 추격 도중에만 스태미나 무제한. 포획/이탈/개발OFF 시 즉시 일반 규칙으로 복귀한다. 속도/난이도의 기존 추격속도는 유지했다.
- 죽고 남은 목숨으로 재입장하면 북쪽 문 접근 시 새 추격 시도가 시작된다. 괴물 위치/준비시간을 재설정하되 이미 부순 잔해와 바닥에 떨어뜨린 소지품은 보존한다. 상자는 중복 아이템을 생성하지 않는다.
- 성공 탈출 후 재방문은 재추격하지 않는다. 새 판에서는 모든 조리실 상태를 초기화한다. 추적자OFF는 개발 탐방용 우회 기능이다.

## v0.6 추가 시안 구현

| 추가 항목 | 구현 |
|---|---|
| 출석부/자리배치도 | 19개 교실 교탁에서 문서 버튼으로 읽는다. 이름·번호·반장/부반장을 매판 배정한다. 자리표는 번호만 표시하며, 없어진 책상은 `--`, 중앙 통로는 `|`로 표시한다. 실제 책상에 번호 표찰을 붙인다. |
| 칠판/반장 퍼즐 | 잡담/의미심장한 문구를 매판 선택하고 실제 반장 자리 힌트를 둔다. 해당 학년 교무실 열쇠는 같은 층 교실 중 한 반의 반장 책상에 배치한다. |
| 이름 1,000개 | 첨부에서 언급한 별도 xlsx는 제공되지 않았다. 조합한 임시 고유 이름1,000개를 Web/data/student-names.json에 저장했다. 실제 사용 학생 이름은 전체 반에서 중복 없이 배정한다. 출시 전 이름 검수/원본 교체 대상이다. |
| 사물함 | 새 문서의4열×8행으로 외형과32개 개별 조사칸을 맞췄다. |
| 학생 교실 | 항상 그 교실의 전용 열쇠로만 개방. 첫 교실은 공개공간 단서→방향 잠긴 수납함→전용 열쇠의 짧은 루트로 구성한다. 다른 교실 열쇠도 선행 접근 가능한 곳에 배치한다. |
| 구역 카드키 | 시작은 본관1층과 운동장.2층 카드는 잠금 없는 시작 구역,3층/별관/서관 카드는 열린2층 공간,옥상 카드는 열린3층 공간에 배치한다. 카드키 사용 후 출입 권한은 같은 판 동안 유지한다. |
| 옥상 | 카드키 계단에 연결된28×24셀 소형 설비 구역. 환기설비·조사 캐비닛을 배치했다. 최종 옥상 아트는 임시 모듈이다. |
| 특별실 잠금 | 열쇠/쇠사슬/4자리/6자리 중 매판 배정한다. 정답과 쪽지는 같은 시드/잠금ID에서 생성한다. 보건실·음악실 등은 한 가지 주 잠금만 요구한다. |
| 절단기 제한 | 출입문 쇠사슬은 한 판 최대1개. 학생 교실에는 사용하지 않는다. 도구는 대상 방문 밖의 접근 가능한 공간에 배치한다. |
| 저장/불러오기 | Esc→현재 판 저장, 시작 화면→저장한 판 계속하기. 시드/학생·역할/정답/열린 구역·방/읽은 기록/소지품·바닥 드롭/목숨/조리실 잔해를 보존한다. 새 판만 재생성한다. 저장은 추격 장면/문 전환/포획 중 제한한다. |

구역 카드와 사용한 전용 열쇠는 잠금을 해제할 때 소비하여9칸 가방을 비울 수 있게 했다. 절단기는 도구로 남는다. 읽은 문서는 가이드북 기록에 보관해 가방 칸을 소모하지 않는다. 이지 가이드에는 위치, 노말에는 장소 성격 단서, 하드/익스트림에는 구역 목표만 표시한다. 실제 퍼즐 문서는 모든 난이도에서 읽을 수 있다.

## 선택·제약

정해지지 않은 선택은 합리적인 기본안으로 기록했다: 수동 저장1개/브라우저별 저장, 소형 옥상 설비 구역, 상자 보상 초코바, 실패 시 같은 판 잔해 보존, 성공 이후 재방문 재연출 없음. 잠금 없는 구역의 문과 내려오는 계단은 정상 통행한다. 당직자도 아직 잠긴 방/구역을 배회 이동으로 통과하지 않는다.

웹 런타임 구현이다. 공통 지도·사물함·상자는 Unity 데이터에도 반영했지만 새 카드키·퍼즐·세이브·조리실 시스템의 Unity 네이티브 이식은 남아 있다. 실제 Unity 실행은 Editor 라이선스 오류로 Play에 진입하지 못했으며 Unity WebGL 검증도 하지 못했다. 웹 실행물을 Unity WebGL이라고 부르지 않는다.
