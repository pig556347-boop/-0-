# 0.12 별관과 추격 피아노 — 2026-10-26

사용자가 보낸 입체 전개도와 이번 요청을 기준으로 제작. 다른 게임 자산·코드는 사용하지 않았다.

## 별관 구성

본관2층 동쪽 긴 연결통로 끝에서 E → 별관2층 공용 복도. 서관은 기존 봉쇄 상태를 유지한다.

- 1층: 급식실(12개 식탁·배식대·우회통로), 급식실 창고.
- 2층: 공용 복도, 학생 남/여 화장실, 체력단련실, 체육용품 창고, 작은 제어실, 학생휴게실, 체육 이론 교실, 체조·무용 실습실.
- 체육관: 2층에서 출입하며2~3층 높이를 통으로 사용한다. 중간3층 바닥이나 별도3층 체육관 인스턴스는 없다. 높은 벽·2단 창문·코트·농구대·무대·관람 벤치로 표현했다.

공용 복도와 체육관을 포함해 별관12개 독립 공간. 모든 방은 기본 닫힌 문으로 E 출입하고 현재 공간만 보인다. 1층↔2층은 계단에 걸어 들어가 자동 이동한다. 추적자와 나침반도 별관의 문·계단 연결을 사용한다.

## 소리

추격 시작 시 기존 실내/실외 느린 피아노 패턴을 멈추고,192BPM 3/4박자의 고음 피아노로 전환한다. 한 마디는8분음표6개, 첫박 강세와2·3박 보조강세, 짧은 감쇠로 구현했다. 고음역은 MIDI84~92. 추격이 풀리면 원래 장소의 배경음이 돌아온다.

같은 공간에서16m 이내 괴물의 거친 숨소리, 가까운 무거운 발소리, 추격 개시 위협음을 거리별 음량으로 출력한다. 위협음은5초 재생 제한. 일시정지·인벤토리·음소거·탭 숨김에서 기존 음향 정지 규칙을 따른다. 기존 스마트워치 심박은 별도 유지한다.

## 정하지 않은 사항에 적용한 기본안

- 추가 체육 교실: 체육 이론 / 체조·무용 실습실.
- 통층 높이7.6m, 제어실9×9셀로 다른 시설보다 작은 공간.
- 이번에는 열쇠 A/B/C 배치를 기존 본관+운동장에 유지한다. 별관에서도 가구 조사를 할 수 있고 일반 물품은 기존 층별 랜덤 배치에 포함된다.
- 가이드북은9칸 소지품과 별도 전용 버튼이며 목숨/난이도 규칙은0.11 유지.

## 자산과 남은 작업

확보: 기존 자체 모듈·표면·폰트. 임시 제작: 체육기구/배식시설/체육관 외형 모듈과 독자 합성 피아노·괴물 소리. 추가 필요: 최종 체육시설 모델·마감 재질, 실제 피아노/괴물 녹음 및 믹싱. 다른 게임 음원 사용 없음.

별관 지도·출입/계단 스키마는 Unity에도 반영했다. 새 추격 피아노와 괴물 소리는 웹 구현이며 Unity 음향 이식은 남아 있다. Unity Play/WebGL 검증은 유효한 Editor 라이선스가 없어 완료하지 못했다.

## 검증 및 재개 지점

정적 지도82,546개, 기존 런타임81개(64시드,5,076경로), 별관 연결38개 통과. 실제 Chromium80개 검사 통과, 콘솔·실행 오류0. 별관 문 왕복/키보드 자동계단/추적자 문 추적/3박자 고음 피아노와 괴물 음향 출력/일시정지/열쇠 교문 성공을 확인했다. 전개도71개 화면과PNG6개 로드 통과. 공개 주소 검사 결과는 Evidence/annex-public-runtime.json과 Deploy/publication.json에 기록한다. 재개 시 이 문서와 해당 보고서의 실행물 해시를 대조한다.

검사 중 두 추격 장면을 프레임 간격 없이 연속 설정하던 브라우저 검사 코드를 수정했다. 추적자OFF 상태를 음향에 반영하고5초 재생 제한이 끝난 뒤 새 추격 시작음을 검사한다. 실제 소리는 최초 추격에서 정상 재생되었으며, 이 수정은 검사 설정에만 해당한다.
