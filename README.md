# 폐교탈출 0.10 — 운동장 교문 탈출

본관53방과 운동장을 탐방해 A·B·C 열쇠를 모으고 **운동장 남쪽 교문에서 E**로 탈출합니다. 본관1층 현관문은 E로 운동장과 왕복하는 출입구입니다.
열쇠는 매판 본관과 운동장에 최소1개씩, 나머지1개는 무작위로 배치합니다. 가구를 조사하거나 지면에서 줍습니다.

처음 외부 안내에서는 **Open the page**, 게임에서는 **폐교에 들어가기**를 누르세요.
WASD/방향키 걷기, Shift 달리기, E 문·조사·줍기·교문, F 문과 겹친 조사, I 가방, Esc 정지. 개발 추적자ON/OFF 제공.

현재지도: [전개도](maps/index.html), [운동장 실제 배치](maps/playground.png). 상세구현: docs/PLAYGROUND_RUNTIME.md.

독립 Three.js 브라우저 실행물이며 UnityWebGL 빌드가 아닙니다. 실제UnityC#컴파일성공, Play는라이선스문제로미검증입니다.
기존main·다른게임·사이트설정을 변경하지 않는 폐교탈출 전용 브랜치입니다.
