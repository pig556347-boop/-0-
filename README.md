# 폐교탈출 0.14

본관1층부터 카드키를 찾아 탐색 범위를 넓힙니다. I 가방→별도 가이드북에서 목표와 단서를 확인하세요. 교실은 전용 열쇠, 특별실은 문에 표시되는 열쇠/쇠사슬/4·6자리 번호로 엽니다. 교탁의 출석부와 자리배치도로 반장 책상을 찾을 수 있습니다. Esc에서 저장, 시작 화면에서 저장한 판을 계속합니다.

조리실 길 끝 상자를 조사한 뒤 북쪽 출입문으로 돌아오면 추격이 시작됩니다. 그동안 스태미나는 무제한이며 죽고 재입장하면 다시 시도합니다. 성공 후 재방문에는 부순 길을 유지합니다.
