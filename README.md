# 폐교탈출 0.22

[플레이](index.html) · [변경 사항](PATCH_022.md) · [검증](build.json)

괴물을 피해 학교의 기록을 따라 교문 열쇠 하나를 찾아 탈출합니다. 특별실 미니게임은 제거했으며 당직자와 조리실 괴물만 활성화했습니다. 조리실 괴물의 크기는 플레이어 3 : 괴물 25입니다.

WASD 이동 / Shift 달리기 / E 문·은신·교문 / F 가구 조사 / I 소지품·가이드북 / Esc 일시정지.

0.22 전용 저장 슬롯입니다. 이전 저장은 지우지 않고 남겨둡니다. 독립 브라우저판이며 Unity WebGL이 아닙니다. Unity 코드 컴파일은 통과했지만 라이선스 제한으로 Unity Play는 검증하지 못했습니다.
