# 폐교탈출 0.8 — 독립 웹 플레이

본관 1~3층, 41개 방 탐방에 배회·감각 기반 추격과 랜덤 아이템·탈출을 추가했습니다.

처음 외부 콘텐츠 안내가 뜨면 **Open the page**, 게임에서 **폐교에 들어가기**를 누르세요.

- WASD/방향키 이동, Shift 달리기, E 문·조사·줍기·교문, F 문과 겹친 물건 조사.
- I 인벤토리: 9칸과 별도 착용 1칸. 사용·착용·버리기는 인벤토리 버튼입니다.
- 개발 추적자 ON/OFF 버튼, Esc 일시정지, 새 판은 아이템과 스폰을 다시 추첨합니다.
- 열쇠 A/B/C를 모아 1층 현관 임시 교문에서 E로 탈출합니다.
- 비타민워터: 2초간 +30%, 초코바: 스태미나 100%. 시계 부품 3개는 나침반 자동 합성, 스마트워치는 접근 심박음입니다.

자체 브라우저 검토판이며 Unity WebGL 빌드가 아닙니다. Unity 소스는 별도 SchoolEscape 프로젝트에 보존합니다.
기존 main/다른 게임/기존 사이트를 변경하지 않는 전용 브랜치입니다.
