# 폐교탈출 0.13

본관·운동장에서 A/B/C 열쇠를 모아 운동장 남쪽 교문에서 E로 탈출합니다.
시작 화면에서 이지/노말/하드/익스트림을 선택하세요. I 가방 → 가이드북에서 목표와 난이도에 따른 단서를 읽습니다.
WASD 이동, Shift 달리기, E 문·조사·교문, F 겹친 조사, I 가방, Esc 닫기/정지.
조사는 수납창을 열고 사물함 칸을 선택한 뒤 물건을 클릭해 가져갑니다.

본관2층 서쪽→서관, 동쪽→별관. 체육관 가장자리3층 관람통로/조사실3개와 탈의실을 추가했습니다. 별관급식실 옆 조리실에서 북쪽문으로 나가려E를 누르면 추적자ON일 때 붕괴·배식장 추격이 시작됩니다. 서쪽 비상문으로 탈출하세요. 실제로 부순 길은 같은 판 재방문 시 유지됩니다.
[전개도](maps/index.html)는 기본 배치 예시입니다. 매판 배치는 게임 Tab과 가이드북에서 확인하세요.
[상세 규칙](docs/EXPANSION_013.md)

독립 Three.js 웹 실행물이며 Unity WebGL 빌드가 아닙니다. 새 게임플레이 시스템은 웹 구현입니다.
기존 main과 다른 게임은 변경하지 않습니다.
